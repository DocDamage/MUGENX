## 🛠️ **TROUBLESHOOTING**

### "Character won't load"
**Check:**
- Is folder in chars/ directory?
- Does .def file exist?
- Is character in select.def?

**Fix:**
- Verify file paths
- Re-extract ZIP
- Try different character

### "Game crashes"
**Check:**
- Are SFF/SND files present?
- Is character compatible?
- Check error log

**Fix:**
- Remove last added character
- Download different version
- Try simpler character first

### "No characters showing"
**Check:**
- Is select.def updated?
- Are paths correct?
- Did script run successfully?

**Fix:**
- Run quick_play_setup.py again
- Manually edit select.def
- Verify folder structure
