기본공격

x      :    약베기
y      :    중베기
a      :    강베기
b      :    킥

x+y (혹은) z                      : 회피

접근 → + x+y (혹은) 접근→ + z   : 상대뒤로 돌아가기

y+a 혹은 ↓ + c                   : 중단베기(앉아가드불능)

접근 → + a                       : 가드해체(밀기)

접근 ← + a                       : 가드해체(당기기)

→ + b                            : 서서하단킥(하단판정)

↘ + b                            : 하단강킥공격

→→                              : 대시

←←                              : 백대시

다운공격                          : 상대다운시 ↘ + 베기

굴러일어나기                      : 다운시 ← 혹은 →

빨리일어나기                      : 다운시 ↑




시동베기         :a+b 혹은 c

연속베기1        :a+b 히트중 x x x

연속베기2        :a+b 히트중 y y a (필살기로캔슬,공중콤보가능)

연속베기3        :a+b 히트중 x y a

14연베기         :a+b 히트중 → + x x y y a a x y a a a a a 
                   (성공시 파워게이지 MAX)


대시공격   : 대시중 x 혹은 y 혹은 a 혹은 b




-필살기-

파워 그라데이션  : →↓↘ + 베기

스플래시 판트    : → + 베기연타

트라이 슬래시    : ↓↘→ + 베기 (누르고 있으면 페인트, 파워MAX시 강화) 


-초필살기-

스플래시 그라데이션 : ← → ↓ + x+y 혹은 z  
                    (히트중 → + y혹은 a혹은 b) - [미완성]


-분노폭발모드- (폭발후 powerMAX가 풀린후부터는 power가 모이지 않습니다)
[모든라운드당 1번가능]

분노폭발 : x+y+a 혹은 z+a
연속베기 : 분노폭발중 x+y+a(연타로 히트수증가) - [미완성]
일섬     : 분노폭발중 혹은 분노폭발 연속베기중 y+a+b 혹은 y+c
