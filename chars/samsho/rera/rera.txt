  I - About this version
 ========================

  I.I - What's this ?
 =====================

Rera is a character from the fighting game Samurai Shodown V Special, originally created by 
SNK Playmore and Yuki Enterprise for the Neo-Geo console, and converted to the PC game engine 
M.U.G.E.N. by R.o.q.u.e.

The M.U.G.E.N. engine was created by Elecbyte (" http://www.elecbyte.com "). You can find it by 
wandering through the Web sites of the Mugen community.

My other works are available at " http://sunnyworld.fr.st ". Check this place to have the latest
official versions.


  I.II - What's in ?
 ====================

Nearly everything from the original game, plus some bonuses:

 - All standard, special and super moves from Samurai Shodown V Special.
 - Shikuruu (wolf) and all the moves associated with it.
 - A couple of additional attacks.
 - 12 palettes: 4 from SS5, 4 from SS5 Special and 4 original.
 - Dizzy code, Guard Crush code, AI Activation code...
 - Blood sparks.
 - ...

To all the people making SS chars : my version of Rera uses the animations 5320 and 5325 as 
standard animations for guard crushing.


  I.III - What's missing ?
 ==========================

 - Kenki gauge.
 - Animations for fatalities.
 - Some blood sparks.
 - Some sounds.
 - New moves?
 - New gameplays?

The Kenki gauge is not included : I do not like to create and display additional bars in the 
Mugen interface. Moreover, I could not figure how the calculations for the damages were done. 
Thus, I divided by two her damages. For these two reasons, I do not plan to add this feature 
in the future.

I do not really think anybody will convert or update SS characters to the Mugen Engine. Thus 
I don't think I will add the fatalities animations. If you are making such a character and you 
would like to create some "interactivity" at this level, you can contact me on the forums I 
usually attend to (I do not give e-mails due to some spamming issues).


  I.IV - Main differences with Samurai Shodown V Special
 ========================================================

Here are the main differences with the original game :

 - Character cannot loose her weapon.
 - No Kenki gauge and no variations in the damages.
 - Added the overhead slash attack.
 - Added the Epunkine Shikite and the Kamui Risse special attacks.
 - Mu No Kyouchi Mode can be activated anytime.
 - Some commands were changed.
 - Some graphic elements are different.


  I.V - Known bugs
 ==================

This version of Rera is based on Nakoruru. Although I changed many elements (sprites position, 
timings, collision boxes, damages...) the programming globally remains the same. Since Nakoruru 
was deeply tested (my thanks to Winane for that) Rera should hardly any bugs lefts. Nothing is 
perfect however, so if you find any, thanks to report them to me.

 ===============

 ====================

Light Slashes	: [x]
Medium Slashes	: [y]
Fierce Slashes	: [x] + [y]
Kicks		: [a]

Knockdown Kicks : [fwd]  + [a] (standing)
		: [fwd]  + [a] (crouching)
		: [down] + [a] (air)

Overhead Slash	: [x] + [a] (must be blocked high)
Overhead Kick	: [y] + [a] (must be blocked high)

Pursuit Slash	: [fwd] + [down] + [x] + [a] (when enemy lying on ground)
Pursuit Kick	: [fwd] + [down] + [y] + [a] (when enemy lying on ground)

Guard Crush	: [fwd]  + [y] + [a] (when enemy is close - push him !)
		: [back] + [y] + [a] (when enemy is close - pull him !)
Attack		: any slash while guard crushing
Air Throw	: [fwd] + [a] (when enemy is close in the air)

Meditate	: [b]
Hop Forward	: [b] + [fwd]
Lower Evade	: [b] + [back]
Lay Down	: [b] + [down]
Roll Forward	: [b] + [down] + [fwd]
Roll Back	: [b] + [down] + [back]

Air  Recover	: [b] (when falling in the air)
Safe Landing	: [b] (just before hitting the ground)

Roll  Recovery	: [back] or [fwd] (when lying down)
Quick Recovery	: [up]   	  (when lying down)

Triangle Jump	: [up] at the edge of the screen

Kamui Risse	: [back], [down], [down] + [back], [back] + [x] (one cape twirl)

		  [back], [down], [down] + [back], [back] + [x] + [y] (three cape twirls)

Reflect		: [down], [down] + [back], [back], [fwd] + [a] (counters ground normal attacks)

Suicide		: [back], [fwd], [down] + [start]

Taunt		: [start]

  II.III - Special Modes
 ========================

Rage Mode :
-----------
Each time Rera is hit, her Power Bar increases. When the Power Bar is full, Rera becomes enraged 
for a short time. Her damages increase and a new attack becomes available.
	Nubeki Kamui Shikite : [down], [down] + [fwd], [fwd] + [a] + [b]

Rage Explosion Mode :
---------------------
Rera can enter the Rage Explosion Mode anytime. While in the Rage Explosion Mode, Rera becomes 
enraged for a short time. Like in the Rage Mode, her damages increase and the Nubeki Kamui 
Shikite becomes available as well. As soon as the Rage Explosion Mode is activated, the Power 
Bar is destroyed and becomes unusable for the rest of the match.
	Rage Explosion Mode : [a] + [b]

If Rera is in the Rage Explosion Mode and if her enemy has little life left, a new attack 
becomes available.
	Irusuka Emushi Newa Shikite : [down], [down] + [back], [back] + [a] + [b]

Mu No Kyouchi Mode :
--------------------
Rera can enter the Mu No Kyouchi Mode anytime. In the Mu No Kyouchi Mode, the enemy's moves are 
slowed for a short time. Just like in the Rage Explosion Mode, as soon as Mu No Kyouchi Mode is 
activated, the Power Bar is destroyed and becomes unusable for the rest of the match.
	Mu No Kyouchi Mode : [down], [down] + [back], [back] + [a] + [b]

During the Mu No Kyouchi Mode, a new attack becomes available.
	Issen : [a] + [b]
