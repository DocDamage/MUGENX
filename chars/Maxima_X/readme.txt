 Installation
+++++++++++++++
 DownLoad 1 file named "Maxima_0101.zip" or "Maxima_1129.zip".
 The "Maxima_????.zip"  contains 23 files shown below.
  Maxima.air		Maxima07.act
  Maxima.cmd		Maxima08.act
  Maxima-N.cns		Maxima09.act
  Maxima-S.cns		Maxima10.act
  Maxima-H.cns		Maxima11.act
  Maxima.def		Maxima12.act
  Maxima.sff		Maxima.snd
  Maxima01.act		ReadMe_J.txt (In Japanese)
  Maxima02.act		ReadMe.txt (In English, this file)
  Maxima03.act		Skill.zip (Containes commands)
  Maxima04.act		
  Maxima05.act		
  Maxima06.act

 Unzip a file then, put these files into 1 folder named "Maxima".
 Then Put "Maxima" folder into your Mugen "charas" folder.

 Ex.)
   muk00101-----charas
              :    |____Maxima
              :    :       |____Maxima.air
              :    :       :
              :    :       :
              :    :       :

 Add this line in your "select.cfg" (or "select.def")in "data" folder.

 Maxima, stages/******.def

 Replace ****** with your favorite background name.

 Ok, run your Mugen then the Maxima's face is added your character
 select screen. Let's enjoy !!!

++++++++++++++++
 Commands
++++++++++++++++
 Unzip "Skill.zip".
 Please show "Skill_E.htm" in the "Skill" folder.
 Button layout is below...

  X Y Z
 (l ; :) : Deffault Keys
  A B C
 (, . /) : Deffault Keys

 X...Light Punch  ,  Y...Hard Punch  ,  Z...Recover
 A...Light Kick   ,  B...Hard Kick   .  C...Extra Hard Attack

++++++++++++++++++
 Featuers
++++++++++++++++++
 / Air recover or fall recover
   Press X+A or Z Button , when he can recover.

 / Quick forward or backward
   Press X+A or Z Button on the ground.

 / Guard cancel quick forward or backward (Costs half power gauge)
   Press X+A or Z Button , when he guarded.

 / Guard cancel Extra Attack (Costs half power gauge)
   Press Y+B or C Button , when he guarded.
