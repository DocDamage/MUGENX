==========================japanese=================================
※AIのON/OFF
Sailor_Mars.defを開けて（txt形式で）

cmd     = mars_AI.cmd;use AI
;cmd     = mars.cmd;no AI

を

;cmd     = mars_AI.cmd;use AI
cmd     = mars.cmd;no AI

に変更して、セーフでOK

※脱衣KOのON/OFF
AIありならmars_AI.cmdを、AIなしならmars.cmdを開けて　（txt形式で）

[State -1, setting];ero;脱衣KO ON(1)/OFF(0)
type = varset
trigger1 = 1
v = 39
value = 1   ←1=ON

のvalue = 1をvalue = 0に変更して、セーフでOK

※アクション顔のON/OFF
AIありならmars_AI.cmdを、AIなしならmars.cmdを開けて　（txt形式で）

[State -1, setting];kao;アクション顔画像
type = varset
trigger1 = 1
v = 46
value = 1　　←1=ON

のvalue = 1をvalue = 0に変更して、セーフでOK

※アクション顔の座標（アクション顔がOFFだったら無効）
mars.cnsを開けて、（txt形式で）
[State 915,xy];1Pface_xでサーチ

[State 915,xy];1Pface_x
type = varset
trigger1 = 1
v = 47
value = -3　　　←1P X座標

[State 915,xy];1Pface_y
type = varset
trigger1 = 1
v = 48
value = 18　　　←1P Y座標

そして[State 915,xy];2Pface_xでサーチ

[State 915,xy];2Pface_x
type = varset
trigger1 = 1
v = 47
value = -1　　　←2p X座標

[State 915,xy];2Pface_y
type = varset
trigger1 = 1
v = 48
value = 18　　　←2P Y座標

頑張ってください
==========================English=================================
※AI ON/OFF
open the file Sailor_Mars.def（use by txt）

cmd     = mars_AI.cmd;use AI
;cmd     = mars.cmd;no AI

change it to

;cmd     = mars_AI.cmd;use AI
cmd     = mars.cmd;no AI

save it and it's OK

※HENTAI ON/OFF
if you use AI open the file mars_AI.cmd
if you no use AI open the file mars.cmd　（use by txt）

[State -1, setting];ero;脱衣KO ON(1)/OFF(0)
type = varset
trigger1 = 1
v = 39
value = 1   ←1=ON

change value = 1 to value = 0 and save

※action face ON/OFF
if you use AI open the file mars_AI.cmd
if you no use AI open the file mars.cmd　（use by txt）

[State -1, setting];kao;アクション顔画像
type = varset
trigger1 = 1
v = 46
value = 1　　←1=ON

change value = 1 to value = 0 and save

※action face's XY（only action face ON）
open the file mars.cns（use by txt）
use search to find [State 915,xy];1Pface_x

[State 915,xy];1Pface_x
type = varset
trigger1 = 1
v = 47
value = -3　　　←1P X

[State 915,xy];1Pface_y
type = varset
trigger1 = 1
v = 48
value = 18　　　←1P Y

then use search to find [State 915,xy];2Pface_x

[State 915,xy];2Pface_x
type = varset
trigger1 = 1
v = 47
value = -1　　　←2p X

[State 915,xy];2Pface_y
type = varset
trigger1 = 1
v = 48
value = 18　　　←2P Y
