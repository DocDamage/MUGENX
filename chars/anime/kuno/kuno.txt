INSTALLATION:
-------------

1. Unzip KUNO.ZIP into MUGEN\CHARS\KUNO\

2. edit MUGEN\DATA\SELECT.CFG and insert the following line:

   kuno, stages/flames.def

   (FLAMES is just an example, insert a valid stage!)



THE BUTTON SYSTEM: (4-button pad: a,b,c,d  6-Button pad: a,b,x,y)
---------------------------------

A            -  Light Stab

B            -  Light Slash
 
C            -  Strong Stab

D            -  Strong Slash



ADVANCED BASIC-MOVES:
---------------------

Assault Run                  :  F, F

Escape Hop                   :  B, B

Mid-Air Recover (after hit!) :  a + b (during Fall)

Power-Gauge-Charge           :  (hold) a + b



THE SPECIAL MOVES:
------------------

Ko-kuu Zan (Slow)           :  QCF  +  b

Ko-kuu Zan (Fast)           :  QCF  +  d

Tenchi-raimei-kiri          :  F, D, DF  +  a

Shin Tenchi-raimei-kiri     :  F, D, DF  +  c

Tenchi-raimei-kiri-densetsu :  F, D, DF  +  d

Cyclone-Slash (fast)        :  QCB  +  a

Cyclone-Slash (fierce)      :  QCB  +  c

Sword Dash                  :  QCB  +  d




DESPERATION MOVES:
------------------

Ko-kuu Zan Densetsu (level 1)    :  QCF, QCF +  a

Ko-kuu Zan Densetsu (level 3)    :  QCF, QCF +  c

Super Cyclone Slash (level 1)    :  QCF, QCF +  b

Super Cyclone Slash (level 3)    :  QCF, QCF +  d


IMPORTANT:

if you pack too much hits, kuno might get dizzy for a few seconds,
