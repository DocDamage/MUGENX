---------------------------------------------------------------

-=[4.1 Normal Attacks]=-

- Jab Punch
	X
- Strong Punch
	Y
- Fierce Punch
	Z
- Light Kick
	A
- Forward Kick
	B
- Roundhouse Kick
	C
- Throw Punch
	(close) F + Z
- Throat Kick
	(close) F + C

-=[4.2 Speical Attacks]=-

- Chaos Flare
	D, DF, F + Punch
- Bat Spin
	D, DB, B + Kick
- Vampire Kiss
	D, DF, F + Kick
- Demon Cradle
	F, D, DF + Punch
- Dashing Demon Cradle
	During Dash, F, D, DF + Punch
- Negative Stolen
	Close, F, DF, D, DB, B + Punch (*in dashing too)
- Ground Pursuit
	When P2 is Down, X + A  or Y + B

-=[4.3 ES/EX Attacks]=-

* Dark Force
	Fierce Punch + Roundhouse Kick
- ES Chaos Flare
	D, DF, F + 2Punches

	D, DB, B + 2Kicks
- ES Demon Cradle
	F, D, DF + 2Punches
- ES Dash Demon Cradle
	Dash Back/Forward, F, D, DF + 2Punchs
- EX Midnight Bliss
	Hold B, F + 2Kicks
- EX Demon Billion
	F, D, DF + 2Kicks
- EX Positive Stolen
	D, DB, B + 2Punches
- EX Midnight Pleasure
	Hold B, F + 2Punches
