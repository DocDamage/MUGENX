How to install
--------------

 - Create a folder called "VICTOR" in the CHARS folder of MUGEN.
 - Extract the files to the previously created folder.
 - Edit the file SELECT.DEF in the DATA folder and add the line "VICTOR" in
   the [Characters] section.

------

 UB  U  UF
            LP  MP  HP
   O O O
    \|/     x   y   z
 B O-+-O F

   O O O
            LK  MK  HK
 DB  B  DF

Normal motions
--------------

 - Chin Basher                          F/B + MP (close)
 - Two-Handed Squeeze                   F/B + HP (close)
 - Bottom Grip                          F/B + MK (close)
 - Mega Shock                           F/B + HK (close)

Special motions
---------------

 - Gyro Crush                           D,DB,B + P
 - Giga Burn                            D,DB,B + K
 - Mega Forehead                        hold B,F + P
 - Giga Buster                          hold B,F + K
 - Graviton Knuckle                     360 + P
 - Mega Spike                           360 + K
 - Pounce                               U + P/K

Hyper motions
-------------

 - Hyper Gyro Crush                     D,DB,B + PP
 - Hyper Giga Burn                      D,DB,B + KK
 - Giga Brood                           hold B,F + PP
 - Hop Kick                             hold B,F + KK
 - Mega Stake                           hold D,U + PP
 - Thunder Break                        hold D,U + KK
 - Hyper Pounce                         U + PP/KK

Comments
--------

 - Fast recovery: tap P and K buttons.
 - Autoguard mode: select the character with START + P/K.
 - Combos: light attacks can be cancelled into medium and hard ones, and
   normal attacks, into special and hyper ones.
