 ====================================
  SasquatchX AI SWITCH Documentation
 ====================================

 There are 3 types of ai for SasquatchX.. 
 Open the sasquatchX.def file with notepad or any text viewer.
 Just remove the semicolon ";" before the type you want to use
 and make sure the others have semicolon.

 Sample:
 
-----------------------------------
 Using MEDIUM AI
 
 ;cmd = Squatch.cmd
  cmd = MedAI.cmd 
 ;cmd = NoAI.cmd
-----------------------------------
 Using HARD AI

  cmd = Squatch.cmd
 ;cmd = MedAI.cmd 
 ;cmd = NoAI.cmd

-----------------------------------
 Using No ai (lame, stupid :P)

 ;cmd = Squatch.cmd
 ;cmd = MedAI.cmd 
  cmd = NoAI.cmd

-----------------------------------
