落とした人が持ちキャラとしてガンガン使ってやってくれると幸いです。

===========================================================================
 留意点
===========================================================================

・空中で何度でも攻撃が出せるヴァンパイアの仕様を導入している(一部不完全)。
・空中ダッシュは完全に原作通りではない。
・結構高さのあるステージで+Bを出すと、蜂の巣の位置がやや不自然
・Qjで、空中にいる敵を蜂蜜で固めてしまうことがある
・コンボで敵を仕留めたとき、コンボテロップが出ない
・M.U.G.E.N1129のバグのため、画面左端でアドバンシングガードを発動しても敵を押し戻せないことがある。
・これもM.U.G.E.N1129のバグのため、画面左端でSxPを永久にガードさせ続けることができてしまう。

 コマンド説明

---------------------------------------------------------------------------
ボタン対応表
---------------------------------------------------------------------------

	a = 弱キック
	b = 中キック
	c = 強キック
	x = 弱パンチ
	y = 中パンチ
	z = 強パンチ

	start = 挑発

---------------------------------------------------------------------------

コマンドに使われている数字はテンキーに相当します。
コマンドは自分が右向きの時のものです。

S×P (空中可)
	a/b/c ボタン連打

C→R (空中可、ES有り)
	41236, x/y/z

O.M. (コマンド投げ、ES有り)
	63214, y/z

R.B. (ガードキャンセル専用、ES有り)
	(ガード中に)623, a/b/c

ΔA (空中可、ES有り)
	214, a/b/c


---------------------------------------------------------------------------
超必殺技
---------------------------------------------------------------------------

+B (空中可,要1000power)
	41236, キックボタン2つ以上同時押し

Qj (空中可,要1000power,地上で当たると敵を一定時間固められて追撃可)
	623, パンチボタン2つ以上同時押し


---------------------------------------------------------------------------
ダークフォース
---------------------------------------------------------------------------

i2 (空中遊泳, 要1000power, 同コマンドで中断可)
	同じ強さのキックボタンとパンチボタン2つ同時押し


---------------------------------------------------------------------------
その他
---------------------------------------------------------------------------

Cn (投げ)
	(投げの間合いで) 6/4, y/z

Ca (空中投げ)
	(ジャンプ中に投げの間合いで) 6/4, y/z

【ダッシュ中断】
	(前ダッシュ中に) 4

【移動起きあがり】
	(ダウン中に) 6/4を入れながら攻撃ボタンどれか

【追撃】
	(敵ダウン中に) 28, a/b/c

【空中浮遊】
	ジャンプ中に↑押しっぱなしでしばらく静止

【アドバンシングガード】
	ガード中に攻撃ボタン連打で、ガード状態を強制解除＆敵押し戻し

【ES技】
	1000power以上の時、必殺技コマンド+攻撃ボタン2つ以上同時押しで出せる強化技。

【ヴァンパイアシステム】
	ファーストアタック、4・8・12連コンボ、各種Finish、アドバンシングガード、
	ガードキャンセル、リバーサルetcの時にヴァンパイア固有のテロップを表示。
