MOVES
---------------------------------------------------------------------
Dark Force (needs power 1)            	: P1+K1 or P2+K2 or P3+K3

Kill Shred (release/recall sword)	: D, DB, B + KICK (3 version)
ES Kill Shred (when releasing: pow. 1)	: D, DB, B + 2KICKS

Blade Surf (only with sword)		: D + KICK (in air: 3 version)

Ifrit Sword (only with sword)		: F, D, DF + PUNCH
ES Ifrit Sword (needs power 1)		: F, D, DF + 2PUNCHES
(Ifrit Sword is also his guard cancel)

Blizzard Sword (only with sword)	: B, DB, D, DF, F + PUNCH (3 version)
ES Blizzard Sword (needs power 1)	: B, DB, D, DF, F + 2PUNCHES

Lightning Sword (only with sword)	: B, D, DB + PUNCH (3 version)
ES Lightning Sword (needs power 1)	: B, D, DB + 2PUNCHES

Lightning Fall (after sword is released): B, D, DB + PUNCH (3 version)
ES Lightning Fall (needs power 1)	: B, D, DB + 2PUNCHES

Sword Grapple (special throw)		: F, DF, D, DB, B + MP or HP (close)

Pounce (when opponent is on the floor)	: D,D + PUNCH OR KICK
Pounce ES Version (needs power 1)      	: D,D + 2PUNCHES OR 2KICKS

Change Immortal (needs power 2)		: D, DB, B, D, DB, B + PUNCH or KICK

Press of Death (needs power 2)		: B, DB, D, DF, F + K (3 version)

Advancing Guard			       	: P,P,P (while guarding)

NOTES:
-----
-When liedown, press F or B to slide forward or backward and get up.
-Normal moves can be different if performed with or without the sword.
-During the dark force you can't perform all special moves.
-The daemon of Change Immortal has different color depending on the key used:
LP: Blue
MP: Brown
HP: Red
LK: Green
MK: Emerald
HK: Dark Red
Start: Rainbow
(Dark Brown and violet are AI only)
