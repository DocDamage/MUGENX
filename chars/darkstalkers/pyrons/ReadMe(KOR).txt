3. 조작법

   방향 -	방향키(설정해 놓은)
   펀치 -	x, y ,z (약, 중, 강)
   킥    -	a, b, c (약, 중, 강)


   잡기 -	(근접해서)← or → + 중P or 강P
   도발 -	Start 버튼


  - 특수기

			    - → + P ( 대쉬중 가능 )
		      	    - ↓ + P ( 공중에서 )
   다운공격                 -   (상대방 다운시)↑ + 아무 버튼


  - 필살기

   솔 스매쉬		-   ↓↘→ + P(공중 가능)
   조디악 화이어		-   →↓↘ + P(가드 캔슬로 가능)
   아비터 블레이즈	-   ↓↙← + K(공중에서)
   갤럭시 트립		-   ←↓↙ + 아무버튼(버튼에 따라 이동위치가 틀림)

   플래닛 버닝		-   (근접해서)→↘↓↙← + 중P or 강P


  - ES 필살기

   솔 스매쉬		-   ↓↘→ + PP(공중 가능)
   조디악 화이어		-   →↓↘ + PP(가드 캔슬로 가능)
   아비터 블레이즈	-   ↓↙← + KK(공중에서)

   플래닛 버닝		-   (근접해서)→↘↓↙← + PP

   
   다운공격                 -   (상대방 다운시)↑ + PP or KK


  - EX 필살기

   코스모스 디스렙션    -   ←↙↓↘→ + PP or KK
				(손과 발에 따라 나가는 위치가 조금 달라지고, 버튼을 계속 누르고 있으면 모으기가 되어 발사 형태가 달라짐)
   ??????????		-   ↓↙← + KK (스타트를 누르고 선택했을 경우 가능, 기 게이지 2칸 소모)

4. 약간의 잡설

    드디어 데미트리에 이은 제 두번째 캐러 파이론이 나오게 되었습니다.
   사실, 이미 데미트리를 만들어 놨기 때문에 파이론을 제작하는데에 기존의 데미에서 써먹을 수 있는 부분이 많아
   훨씬 전에 완성을 볼 수 있었는데 귀찮음과 개인적인 사정, 무겐에 대한 식어가는 열정등으로 들인 노력에 비해
   상당히 늦게 나오게 되었습니다.

    원작과 최대한 비슷한 느낌으로 만들려 노력했습니다만 여러분들이 느끼기에는 어떨지 모르겠군요... ^^;;
   
    그동안 이 허접한 캐릭에 관심을 가져주시고 테스트를 해주신 이식의 세계분들과 무한지대 회원 여러분께 진심으로
   감사의 마음을 드립니다.
    더불어 이런 멋들어진 게임과 캐릭터를 만들어준 CAPCOM에게도 경의를......

    버그 신고나 기타 알려주실 점등은 이식의 세계 게시판을 이용해 주시면 대단히 감사하겠습니다.
