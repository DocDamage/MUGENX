; 熱鍵-1 所代表的招式
;
; 設定方法: 參照下列代碼列表, 再將下面的 var(44) = ? 改為所需要的數值.
;           亦可在遊戲中按下Start鈕以選單設定,惟遊戲中設定的選項無法儲存.
;
; (註:以下的ABCD按鈕是指原本月華劍士中的按鈕,不是指MUGEN的abcxyz等按鈕
;     而預設的A、B、C、D分別為MUGEN按鈕中的 x、y、z、a
;     預設的熱鍵-1、熱鍵-2分別為MUGEN按鈕中的 b、c
;     另外下列數值除了1~4為連發之外,其餘招式若要設為連續發出均需透過Var(45)、Var(47)來設定 )
;
;  1 = A鈕連發
;  2 = B鈕連發
;  3 = C鈕連發
;  4 = D鈕連發
;  5 = B+C
;  6 = C+D
;  7 = DB_C
;  8 = DF_A
;  9 = DF_B
; 10 = FDF_A
; 11 = FDF_B
; 12 = BDF_C
; 13 = DB_A
; 14 = DB_B
; 15 = DBDF_AB
; 16 = DFDF_AB
; 17 = DBDF_B
; 18 = DFDF_B
; 19 = DD_A 發動亂舞奧義-上段
; 20 = DD_B 發動亂舞奧義-下段
; 21 = DD_? 發動亂舞奧義-隨機選取上下段
; 22 = DD_?-1 隨機選取上下段,並完整發出亂舞奧義-1
; 23 = DD_?-2 隨機選取上下段,並完整發出亂舞奧義-2
; 24 = DD_?-3 隨機選取上下段,並完整發出亂舞奧義-3
; 25 = DD_?-4 隨機選取上下段,並完整發出亂舞奧義-4
; 26 = DD_?-? 隨機選取一招亂舞奧義完整發出
;
[State 5900, 熱鍵-1的設定值]
type = VarSet
trigger1 = var(44) = 0
var(44) = 5

; 熱鍵-1 的連發設定
