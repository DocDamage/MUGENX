;１Ｐカラー＝｢力」
;特徴･･･ダメージが大きい。通常攻撃で削れる。｢脅かし｣キャンセルで｢五輪連ね｣への昇華が
;　　　 可能。潜在奥義｢二天無双剣｣が使用可能。
;
;２Ｐカラー＝｢技」
;特徴･･･連殺斬によるチェーンコンボが使用可。キャンセル可能な通常技が多い。乱舞奥義が
;　　　 使用可能。
;
;３Ｐカラー＝｢極」
;特徴･･･オリジナル要素。月華２のそれとは違い、｢力｣と｢技｣の有利な点だけ併せ持ち、防御
;　　　 力やゲージの溜まり具合も変化しません。また固められた際の為に、投げ技の性能が
;　　　 強化されていたり、潜在奥義を昇華できたりと、いろいろ付け加えてあります。クリ
;　　　 エイターの追加要素が御嫌いな方は、３Ｐカラーを使用不可にしておいて下さい。ち
:       なみに現在確認されている最強の連続技は、ジャンプＹ→連殺斬(４Ｘ→Ｘ→Ｘ→Ｙ)→
;　　　 キャンセル｢乱舞奥義｣→Ｙ×６→キャンセル｢脅かし｣→昇華｢二天無双剣｣です。
;
