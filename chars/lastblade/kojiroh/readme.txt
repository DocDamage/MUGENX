3. コマンド説明
===========================================================================

---------------------------------------------------------------------------
ボタン対応表
---------------------------------------------------------------------------

	a = 蹴り
	x = 弱剣
	y = 強剣
	z = 弾き


---------------------------------------------------------------------------
必殺技
---------------------------------------------------------------------------

コマンドに使われている数字はテンキーに相当します。
コマンドは自分が右向きの時のものです。
┏━┳━┳━┓
┃7 ┃8 ┃9 ┃
┣━╋━╋━┫
┃4 ┃5 ┃6 ┃
┣━╋━╋━┫
┃1 ┃2 ┃3 ┃
┗━┻━┻━┛

疾空殺
	236, x/y

虚空殺
	623, x/y

翔尾閃
	214, x

無明剣(ゲージMAXの時のみ、無明剣・贄へ昇華可能)
	214, y

瞬塵 (高速移動技:敵をすり抜ける、走行中上半身無敵、必殺技・超奥義でキャンセル可)
	214, a

天地 (追加投げ技、めくり可)
	瞬塵中に、投げの間合いで a


---------------------------------------------------------------------------
超奥義
---------------------------------------------------------------------------

無明剣・贄 (ゲージ2つ消費、ゲージMAXの時のみ無明剣から昇華可能)
	2141236, x+y


---------------------------------------------------------------------------
潜在奥義
---------------------------------------------------------------------------

狼牙・零 (ゲージMAXの時のみ発動、溜め可能、溜めた時間に応じてダメージ増加)
	2141236, y

その他
---------------------------------------------------------------------------

	x連打

	4, x

	6, y

	3, a

	6, a
