 Installation
++++++++++++++++++++
 DownLoad 1 file named "Shigen_0101.zip" or "Shigen.zip".
 (The former is for Mugen 000101. The latter is for Mugen000627 or
 more versions.)
 The "Shigen_????.zip"  contains 17 files shown below.
 Shigen.air		Shigen04.act
 Shigen.cmd		Shigen05.act
 Shigen-N.cns		Shigen06.act
 Shigen-S.cns		ReadMe_J.txt
 Shigen-H.cns		ReadMe.txt -> (This File)
 Shigen.def		Shigen.ico (Face Icon)
 Shigen.sff
 Shigen.snd
 Shigen01.act
 Shigen02.act
 Shigen03.act



 Unzip a file then, put these files into 1 folder named "Shigen".
 Then Put "Shigen" folder into your Mugen "charas" folder.

 Ex.)
   muk10401-----charas
              :    |____Shigen
              :    :       |____Shigen.air
              :    :       :
              :    :       :
              :    :       :

 Add this line in your "select.def" (or "select.cfg")in "data" folder.

 Shigen, stages/******.def

 Replace ****** with your favorite background name.

 Ok, run your Mugen then the Shigen's face is added your character
 select screen. Let's enjoy !!!
