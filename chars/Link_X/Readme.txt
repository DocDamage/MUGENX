Link v0.7 (environ) par RMX et Silencer. Si vous lisez ce fichier, vous savez déjà ke cette 
version est une bêta privée et k'il serait souhaitable k'elle le reste.

Juste pour préciser, certains sprites proviennent d'autres persos(les sparks de la boule et 
de l'onde, certaines fumées, Baitang et l'effet de la tournante), Sepher & Misamu sont ok, 
N64Mario n'a pas encore répondu de son coté (mé vu ke cette release est privée, l'effet est 
kan même présent).


Legende : B = Arrière, D = Bas, F = Avant, U = Haut, S = Start
          P = Poing, LP = Poing faible, MP = Poing moyen, HP = Poing fort
          K = Pied, LK = Pied faible, MK = Pied moyen, HK = Pied fort


Le gameplay de Link est majoritairement basé sur les séries Marvel vs Capcom. Il est donc 
conseillé d'utiliser ce perso sur des stages à haut scrolling.


* Abilités : 

- Petit saut :
  U brièvement

- Gigasaut :
  D, U

- Parade :
  F juste avant de se faire frapper pour parer les coups ki se blokent en garde haute; D 
  pour parer les coups ki se blokent en garde basse.
  Permet de ne pas subir les dégats de garde et laisse l'adversaire vulnérable à une 
  contre-attak immédiate.

- Roulade :
  FF ou BB kan Link est à terre pour se relever en roulé.

- Empaleur :
  DF+LP à coté d'un ennemi à terre.

- KO(pas franchement une abilité mé j'savais pas où le mentionner) :
  Suffit de se prendre suffisamment de coups dans un laps de temps pour y avoir droit...


* Objets : 

- Arc :
  LP+LK
  Maintenez ces touches enfoncées pour ne pas décocher de suite la flèche, maintenez D pour 
  s'accroupir.

- Boomerang :
  MP+MK
  Maintenez D ou U avant de le lancer pour choisir la direction.
  
- Bombe :
  LP+MP
  Autant nocive pour Link ke pour son adversaire...
  Maintenez B ou F avant de la lancer pour choisir la portée.

- Bombe à retardement :
  LK+MK
  Toujours aussi nocive et peut en prime être renvoyée dans la tronche du lanceur mé cette 
  version est imblocable.
  Maintenez B ou F avant de la lancer pour choisir la portée.

- Grappin :
  HP+HK

- Baguette de feu :
  MP+HP

- Baguette de glace :
  MK+HK


* Coups spéciaux : 

- Multi-Slash :
  LP à répétition
  Maintenez D pour s'accroupir.

- Boule Kokiri :
  D, DF, F, P

- Tournante : 
  D, DB, B, P
  Pressez B ou F durant les 1ers ticks de la version MP (F pour la version HP) afin de se 
  déplacer.

- Teleport :
  D, DB, B, K
  Maintenez HK dans la version HK pour prolonger le trajet jusk'au bout de l'écran au 
  maximum.

- Invisibilité :
  D, D, D, S

- Mushu :
  D, DF, F, K


* Supers : 

- Onde Kokiri :
  D, DF, F, 2P

- Biggoron Scombo :
  D, DB, B, 2P
  (QTC signifie "Quick Time Counter" pour la petite histoire)

- Chanson du temps :
  B, F, S

- Danse des illusions :
  B, F, P
