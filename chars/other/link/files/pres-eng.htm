LINK FOR MUGEN - VERSION 0.95

  













 


~ PRESENTATION ~

Link is an original character, from Nintendo's universe, and from the saga which has left his mark on video games : Legend of Zelda. He has been converted for Mugen thanks to RMX (drawings) and Silencer (coding). Then, he has been continued on the code by Eikichi (who has unfortunately disappears ever since...) and Mike Werewolf.

Link for Mugen takes back some elements from many Zelda games, especially from : Ocarina of Time, Majora's Mask (released on Nintendo 64), Oracle of Seasons (released on Game Boy Color), A Link to the Past (released on Super NES), and The Wind Waker (released on Game Cube).

Link is a very complete character, but however, he's not totally finished. Globally, we could say that he is about 95% finished now (the original version released by RMX and Silencer was the 0.70, so about 70% developed).

Link's drawings, even if they're inspired by Zelda games' universe, are completely original (except for some effects). Also, even if many moves come from the different Zelda games, some are news, because of Mugen style.

About gameplay, Link is a unique character in the fighting game world. Indeed, he runs a money system (rupees) combined to a shop system, which allows him at each battle to buy some objects to become more powerful.

Our goal isn't to make Link a cheap character (even if he's already strong !), but to try to make him accurate to Zelda games' spirit, especially in Arcade mode.

If you don't know the magic universe of Zelda, we hope this Link's version for Mugen will encourage you to discover it. And if you already know Zelda, we hope this char will allow you to recognize all the magic of this saga.
