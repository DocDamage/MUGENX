LINK POUR MUGEN - VERSION 0.95

  













 


~ PERSONNALISATION ~

Cette version vous permet de personnaliser Link à votre convenance sur plusieurs aspects. Pour cela, vous devez modifier le fichier "custom.txt", via n'importe quel éditeur de textes (Bloc-notes, WordPad, Word, etc.), et régler les paramètres aux valeurs que vous désirez.

Les principales informations sont données directement dans ce fichier. Voici les options que vous pouvez modifier :

  • Mode Magasin

  • Objets de départ

  • Génération d'items

  • Alerte de niveau de vie

  • Conservation de la vie

  • Conservation du power

  • Maximum de rupees

  • Rupees de départ

  • Bouteilles de départ

  • Bouteilles infinies

  • Maximum de flèches

  • Maximum de bombes

  • Flèches de départ

  • Bombes de départ

  • Nombre de flèches à l'achat

  • Nombre de bombes à l'achat

  • Flèches infinies

  • Bombes infinies

  • Affichage des rupees

  • Affichage des flèches

  • Affichage des bombes

Avant toute chose, notez que les paramètres de départ que vous modifiez s'appliquent également à Link si vous l'affrontez dans les modes Arcade. Dans ces modes, par exemple, si vous décidez d'avoir tous les objets, alors Link aura tous les objets quand vous l'affronterez (et si vous décidez de débutez avec des objets choisis au hasard, Link aura également des objets choisis au hasard lorsque vous l'affronterez). Autre exemple, si vous choisissez de commencer sans objet, que vous en achetez quelques-uns et que vous tombez sur Link, ce dernier n'aura aucun objet (car c'est le paramétrage de départ - ici : pas d'objet - qui s'applique).

Gardez cela à l'esprit lorsque vous définissez les options de personnalisation !

1. MODE MAGASIN

Avec cette option, vous pouvez choisir d'activer ou de désactiver le magasin. Si le magasin est désactivé, alors vous ne pouvez pas acheter d'objet, ni remplir vos bouteilles vides ou encore, acheter des munitions (flèches et bombes).

  • Valeur 0 : Le magasin sera désactivé.

  • Valeur 1 : Le magasin sera activé.

  • Valeur autre : Cette valeur sera ramenée à 1, et donc le magasin sera activé.

La valeur par défaut est 1.

Notez que le fait d'activer ou non le magasin n'a aucune incidence sur les objets que vous possédez, ni sur les flèches et bombes, ni sur les bouteilles.

2. OBJETS DE DEPART

Cette option vous permet de définir les objets que vous transportez dès le départ. Les valeurs classiques vont de 1 à 131071. Chaque objet a une valeur précise (cf. tableau ci-dessous). Pour l'avoir dès le départ, il suffit de donner à l'option la valeur de l'objet en question. Si vous souhaitez transporter plusieurs objets, il suffit de cumuler les valeurs des objets désirés. Par exemple, si vous voulez avoir :

  • Le boomerang (valeur = 4),

  • Le marteau (valeur = 16),

  • Le grappin (valeur = 32),

  • La magie du feu (valeur = 1024),

  • Le bouclier miroir (valeur = 2048),

  • Le Nayru's Love (valeur = 65536).

Il suffit d'additionner ces valeurs : 4+16+32+1024+2048+65536 = 68660. Vous devez donc entrer la valeur 68660 pour avoir tous ces objets dès le départ. La valeur 131071 vous permet de débuter la partie avec tous les objets. Si vous mettez une valeur supérieure à 131071, elle sera ramenée à 131071.

En outre, il existe 3 valeurs "spéciales" pour cette option :

  • La valeur 0 : Vous débutez la partie sans aucun objet. C'est la valeur par défaut de cette option.

  • La valeur -1 : Vous débutez la partie avec des objets choisis au hasard par l'ordinateur.

  • La valeur -2 : Cette valeur est très particulière. Elle indique à Mugen que vous choisirez vos objets de départ au début de la partie. Cette option est principalement utile si vous voulez faire un combat avec un ami en utilisant tous les deux Link, mais avec des objets différents. Dans ce cas, au début de la partie, un menu défilant apparaîtra au-dessus de Link :

Vous pourrez alors faire défiler les options avec les flèches et . Vous aurez le choix entre :

  • No object : Vous démarrez la partie sans aucun objet.

  • Random objects : Vous démarrez la partie avec des objets choisis au hasard.

  • All objects : Vous démarrez la partie avec tous les objets.

Validez avec . Si vous appuyez sur une autre touche, votre choix ne sera pas validé, et l'option par défaut (pas d'objet) s'appliquera. Ceci peut être utile si vous tombez sur Link en mode Arcade : au début du combat, vous aurez tous les deux un choix à faire :

  • Valeur -2 : Choix des objets au début du premier combat ("Mode Objets").

  • Valeur -1 : Choix des objets au hasard.

  • Valeur 0 : Pas d'objet au début du mode.

  • Valeur entre 0 et 131071 : Début du mode avec le ou les objet(s) correspondant.

  • Valeur supérieure à 131071 : La valeur est ramenée à 131071.

3. GENERATION D'ITEMS

Cette option vous permet de choisir si les coups de Link peuvent générer des items ou non. Les items vous permettent de récupérer de la vie, de la magie, des flèches et des bombes. Ils rendent donc ainsi le combat plus facile. Cependant, lorsque vous activez les items, vous récoltez moins de rupees (il manque ceux qui auraient du être générés à la place des items) : vos rupees augmentent donc légèrement moins vite, ce qui peut ralentir l'évolution de votre personnage (et donc rendre les matchs suivants plus difficiles). Bref, quel que soit votre choix, il aura ses avantages et ses inconvénients. A vous de voir !

  • Valeur 0 : Pas d'item généré sur les coups.

  • Valeur 1 : Items générés sur les coups.

  • Valeur autre : La valeur est ramenée à 1.

La valeur par défaut est 1.

4. ALERTE DE NIVEAU DE VIE

Dans les jeux Zelda traditionnels, lorsque le niveau de vie du joueur descend sous un stade critique, une alerte sonore se fait entendre de façon répétitive. Cette option vous permet de reproduire ce phénomène dans Mugen. Ce son est souvent trouvé agaçant (c'est pourquoi il est possible de le désactiver), mais c'est également une alerte utile pour utiliser vos potions de vie à bon escient.

  • Valeur 0 : Pas de son d'alerte.

  • Valeur 1 : Un son d'alerte est joué de façon répétitive lorsque votre vie restante est inférieure à 20% de votre vie totale.

  • Valeur autre : La valeur est ramenée à 1.

La valeur par défaut est 1.

5. CONSERVATION DE LA VIE

Cette option vous permet de conserver votre niveau de vie entre les rounds et les matchs. Le jeu en arcade devient donc un dérivé de mode "Survival". Si vous l'activez, vous devrez gérer vos bouteilles de façon particulièrement judicieuse afin de pouvoir remettre votre vie à niveau dans les situations critiques ! Vos seuls moyens de récupérer de la vie sont alors d'utiliser des potions de vie, des fées, des potions complètes, et de récupérer les items coeur si les items sont activés.

Notez que votre vie est conservée à partir du moment où vous n'êtes pas mis KO (auquel cas, votre vie est complètement régénérée au round suivant). Ainsi, si vous perdez un round au temps, vous démarrerez le round suivant avec le niveau de vie du round qui vient de se terminer, malgré la défaite.

  • Valeur 0 : La vie n'est pas conservée entre les rounds et matchs (mode "normal").

  • Valeur 1 : La vie est conservée entre les rounds et matchs.

  • Valeur autre : La valeur est ramenée à 0.

La valeur par défaut est 0.

6. CONSERVATION DU POWER

Cette option vous permet de conserver votre niveau de power non seulement entre les rounds, mais aussi entre les matchs. Le power est conservé dans tous les cas de figure (que vous gagniez ou que vous perdiez le round).

  • Valeur 0 : Le power n'est pas conservé entre les matchs (mode "normal").

  • Valeur 1 : Le power est conservé entre les matchs.

  • Valeur autre : La valeur est ramenée à 0.

La valeur par défaut est 0.

7. NOMBRE DE RUPEES MAXIMUM

Cette option vous permet de décider du nombre maximal de rupees que vous pouvez transporter. Les valeurs valides vont de 0 à 999. Toutefois, pour être exact, il existe une valeur "spéciale" à 0, puis les autres valeurs correctes vont de 50 à 999.

  • Valeur négative : La valeur est ramenée à la valeur par défaut, 500.

  • Valeur 0 : C'est une valeur spéciale ; le maximum étant de 0, cela signifie qu'on ne peut pas collecter de rupees. C'est pourquoi lorsque vous mettez cette valeur, les rupees ne seront pas générés lorsque vous toucherez votre adversaire (mais les items, s'ils sont activés, seront toujours générés). Cette valeur est notamment utile si vous désactivez le magasin, vu que les rupees ne servent plus à rien.

  • Valeur entre 1 et 49 : Une telle valeur n'est pas incorrecte, mais inutile, du fait qu'il faut avoir au moins 50 rupees pour acheter un objet. C'est pourquoi elle sera ramenée à 0.

  • Valeur entre 50 et 999 : Valeur valide qui deviendra donc le maximum de rupees que vous pouvez transporter.

  • Valeur supérieure à 999 : La valeur est ramenée à 999.

La valeur par défaut est 0.

8. RUPEES DE DEPART

Cette option vous permet de définir le nombre de rupees avec lequel vous commencer la partie. Elle n'est utile que si vous avez activé le magasin. Notez que même en ayant des rupees dès le départ, vous ne pourrez pas acheter d'objet avant le début du second combat.

Les valeurs correctes pour cette option vont de 0 au maximum (fixé à l'option précédente, 7).

  • Valeur négative : La valeur est ramenée à 0.

  • Valeur entre 0 et le maximum : Valeur valide qui devient le nombre de rupees avec lequel vous commencer le jeu.

  • Valeur supérieure au maximum : La valeur est ramenée au maximum.

La valeur par défaut est 0.

9. BOUTEILLES DE DEPART

Cette option vous permet de définir de combien de bouteilles vous disposez au début du jeu, et ce qu'elles contiennent.

Cette option est particulière, puisque ce n'est pas une seule valeur qu'il faut définir, mais quatre (une pour chaque bouteille). Pour chaque bouteille, vous pouvez mettre une valeur allant de 0 à 5 :

  • Valeur 0 : Vous ne possédez pas la bouteille.

  • Valeur 1 : Vous possédez la bouteille, mais elle est vide.

  • Valeur 2 : Vous possédez la bouteille et elle contient une fée.

  • Valeur 3 : Vous possédez la bouteille et elle contient de la potion de vie.

  • Valeur 4 : Vous possédez la bouteille et elle contient de la potion de magie.

  • Valeur 5 : Vous possédez la bouteille et elle contient de la potion complète.

  • Valeur autre : La valeur sera remplacée par 0.

La valeur par défaut est 0 pour les quatre bouteilles.

10. BOUTEILLES INFINIES

Cette option est également particulière. Si vous l'activez, le fait d'utiliser le contenu de vos bouteilles ne les videra pas. Une fois remplies, elles pourront donc être utilisées indéfiniment, sans avoir à les remplir à nouveau. Toutefois :

  • Vous ne pourrez utiliser chaque bouteille qu'une fois et une seule par match.

  • Une fois qu'une bouteille a un contenu, il est impossible d'en changer.

  • Quand une bouteille a été utilisée, elle apparaît en transparence dans le menu Bottles jusqu'à la fin du match.

Voici les valeurs possibles :

  • Valeur 0 : Vos bouteilles sont vidées après chaque utilisation, et peuvent être remplies (utilisation "normale").

  • Valeur 1 : Vos bouteilles sont "infinies", et conservent leur contenu après utilisation.

  • Valeur autre : La valeur est ramenée à 0.

La valeur par défaut est 0.

11. NOMBRE DE FLECHES MAXIMUM

Cette option détermine combien de flèches au maximum vous pouvez transporter.

  • Valeur négative : La valeur est remplacée par 10.

  • Valeur 0 : C'est une valeur spéciale, comme pour le maximum de rupees : cela signifie que vous ne pouvez pas transportez de flèche. En conséquence, les flèches ne seront pas générées sur les coups que vous portez (même si les items sont activés) et vous ne pourrez pas en acheter.

  • Valeur de 1 à 99 : Valeur valide fixant le nombre de flèches que vous pouvez transporter au maximum.

  • Valeur supérieure à 99 : La valeur est ramenée à 99.

La valeur par défaut est 10.

12. NOMBRE DE BOMBES MAXIMUM

Cette option détermine combien de bombes au maximum vous pouvez transporter.

  • Valeur négative : La valeur est remplacée par 10.

  • Valeur 0 : C'est une valeur spéciale, comme pour le maximum de rupees : cela signifie que vous ne pouvez pas transportez de bombe. En conséquence, les bombes ne seront pas générées sur les coups que vous portez (même si les items sont activés) et vous ne pourrez pas en acheter.

  • Valeur de 1 à 99 : Valeur valide fixant le nombre de bombes que vous pouvez transporter au maximum.

  • Valeur supérieure à 99 : La valeur est ramenée à 99.

La valeur par défaut est 10.

13. FLECHES DE DEPART

Détermine combien de flèches vous possédez au départ. Le fait de posséder des flèches n'implique pas que vous pouvez les utiliser !!! Il faut impérativement posséder l'arc pour tirer des flèches.

Les valeurs valides sont comprises entre 0 et le maximum fixé précédemment (cf. 11).

  • Valeur négative : La valeur est remplacée par 0.

  • Valeur entre 0 et le maximum : Valeur valide déterminant avec combien de flèches vous débutez le jeu.

  • Valeur supérieure au maximum : La valeur est remplacée par le maximum.

La valeur par défaut est 0.

14. BOMBES DE DEPART

Détermine combien de bombes vous possédez au départ.

Les valeurs valides sont comprises entre 0 et le maximum fixé précédemment (cf. 12).

  • Valeur négative : La valeur est remplacée par 0.

  • Valeur entre 0 et le maximum : Valeur valide déterminant avec combien de bombes vous débutez le jeu.

  • Valeur supérieure au maximum : La valeur est remplacée par le maximum.

La valeur par défaut est 0.

15. NOMBRE DE FLECHES A L'ACHAT

Détermine combien de flèches vous recevez lorsque vous les achetez au magasin. Les valeurs valides sont comprises entre 1 et le maximum fixé en 11.

  • Valeur 0 ou négative : La valeur est remplacée par 5.

  • Valeur entre 1 et le maximum : Valeur valide déterminant combien de flèches vous obtenez à l'achat.

  • Valeur supérieur au maximum : La valeur est remplacée par le maximum.

La valeur par défaut est 5.

16. NOMBRE DE BOMBES A  L'ACHAT

Détermine combien de bombes vous recevez lorsque vous les achetez au magasin. Les valeurs valides sont comprises entre 1 et le maximum fixé en 12.

  • Valeur 0 ou négative : La valeur est remplacée par 5.

  • Valeur entre 1 et le maximum : Valeur valide déterminant combien de bombes vous obtenez à l'achat.

  • Valeur supérieur au maximum : La valeur est remplacée par le maximum.

La valeur par défaut est 5.

17. STOCK INFINI DE FLECHES

Cette option vous permet d'avoir un stock infini de flèches. Si cette option est activé, vous ne pourrez pas générer de flèches lorsque vous toucher l'adversaire, et vous ne pourrez pas en acheter au magasin.

  • Valeur 0 : Vous utilisez un stock normal de flèches.

  • Valeur 1 : Vous utilisez un stock infini de flèches.

  • Valeur autre : La valeur est remplacée par 0.

Le stock infini de flèches prédomine sur le stock maximal de flèches, ce qui veut dire que si vous réglez sur 0 le nombre maximal de flèches que vous pouvez transportez (donc en théorie, impossible d'utiliser les flèches), mais que vous mettez un stock de flèches infini, vous pourrez quand même tirer des flèches.

La valeur par défaut est 0.

18. STOCK INFINI DE BOMBES

Cette option vous permet d'avoir un stock infini de bombes. Si cette option est activé, vous ne pourrez pas générer de bombes lorsque vous toucher l'adversaire, et vous ne pourrez pas en acheter au magasin.

  • Valeur 0 : Vous utilisez un stock normal de flèches.

  • Valeur 1 : Vous utilisez un stock infini de flèches.

  • Valeur autre : La valeur est remplacée par 0.

Le stock infini de bombes prédomine sur le stock maximal de bombes, ce qui veut dire que si vous réglez sur 0 le nombre maximal de bombes que vous pouvez transportez (donc en théorie, impossible d'utiliser les bombes), mais que vous mettez un stock de bombes infini, vous pourrez quand même lancer des bombes.

La valeur par défaut est 0.

19. AFFICHAGE DES RUPEES

Cette option vous permet de choisir d'afficher ou non les rupees que vous accumulez.

  • Valeur 0 : L'affichage est désactivé.

  • Valeur 1 : L'affichage est activé.

  • Valeur autre : La valeur est remplacée par 1.

Notez que si le magasin est désactivé, ou si le maximum de rupees est réglé à 0, les rupees ne seront pas affichés, même si vous réglez ce paramètre à 1.

La valeur par défaut est 1.

20. AFFICHAGE DES FLECHES

Cette option vous permet de choisir d'afficher ou non les flèches que vous accumulez.

  • Valeur 0 : L'affichage est désactivé.

  • Valeur 1 : L'affichage est activé.

  • Valeur autre : La valeur est remplacée par 1.

Notez que si les flèches infinies sont activées, ou si le maximum de flèches est réglé à 0, les flèches ne seront pas affichées, même si vous réglez ce paramètre à 1.

La valeur par défaut est 1.

21. AFFICHAGE DES BOMBES

Cette option vous permet de choisir d'afficher ou non les bombes que vous accumulez.

  • Valeur 0 : L'affichage est désactivé.

  • Valeur 1 : L'affichage est activé.

  • Valeur autre : La valeur est remplacée par 1.

Notez que si les bombes infinies sont activées, ou si le maximum de bombes est réglé à 0, les bombes ne seront pas affichées, même si vous réglez ce paramètre à 1.

La valeur par défaut est 1.
