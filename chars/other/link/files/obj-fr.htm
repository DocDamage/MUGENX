~ LES OBJETS BASIQUES ~

L'une des grandes particularités de Link pour Mugen est que, comme dans les jeux Zelda, vous pouvez faire évoluer votre personnage au fil du jeu. Pour cela, vous avez la possibilité d'acquérir des objets au fur et à mesure des combats (voir la section "Magasin").

Le principe est relativement simple : au début du jeu (selon vos paramètres de Personnalisation), Link débute sans aucun objet. Puis, à partir du second combat, vous avez la possibilité d'accéder au magasin (si activé) pour acheter de nouveaux objets.

Les objets ont deux buts principaux : vous permettre d'utiliser de nouveaux mouvements d'une part, et vous permettre d'acheter d'autres objets, d'autre part.

Concernant les bouteilles et leur contenu, reportez-vous à la section "Les Bouteilles" pour plus de détails.

Le nombre de flèches et bombes que vous pouvez transporter, et le nombre de flèches et bombes que vous obtenez à chaque achat peuvent se paramétrer dans le fichier de personnalisation (cf. la partie Personnalisation pour plus de détails). Si vous achetez plus de bombes ou de flèches que vous n'en avez besoin, le surplus sera perdu. Vos stocks de flèches et de bombes sont affichés en permanence au bas de l'écran, sur le côté, avec votre nombre de rupees :

Les flèches servent aussi bien pour les flèches normales que pour les flèches empoisonnées et que pour les flèches à tête chercheuse (pour ces types de flèches particuliers, vous devez détenir les objets "flèches empoisonnées" et "flèches à tête chercheuse", respectivement).

Les bombes servent aussi bien pour les bombes normales que pour les bombes à retardement (pour ces dernières, vous devez posséder le symbole hylien).

Lorsque vous atteignez votre maximum de rupees et/ou de flèches et/ou de bombes, l'information devient verte, pour vous indiquer que vous ne pouvez pas transporter plus de ces items.

Notez que les nombres de flèches et/ou de bombes ne s'affichent pas dans trois cas :

  • Si vous avez mis un maximum de flèches et/ou de bombes à 0

  • Si vous avez activé les flèches et/ou les bombes infinies

  • Si vous avez volontairement désactiver leur affichage

Ces trois cas se paramètrent dans le fichier de Personnalisation.
