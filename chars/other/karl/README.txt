HOW TO INSTALL THE CHAR:
extract the .zip file (with fullpath name) in the 'chars' folder of your 
mugen directory. then open the file "select.def" that is in the "data"
folder. 
type under the line "[Characters]" the name "karl" and that's it! enjoy.

=======================| KARL'S COMMAND LIST |==========================

******************************************************
* a = air                                            *
* s = stand                                          *
* c = crouch                                         *
* n = close to opponent                              *
* ~ = hold the button for a little time then release *
* $ = hold the button                                *
******************************************************

-|Standard Moves|-------------------------------------------------------

    a = Weak Kick    (nWK)
