  Controls
  --------

    Basic Controls
    --------------
   
      D - down
      F - forward
      U - up
      B - back
      x - button X (weak punch)
      y - button Y (strong punch)
      z - button Z (hyper punch)
      a - button A (weak kick)
      b - button B (strong kick)
      c - button C (hyper kick)

     

    Standard Movement
    -----------------
      U              - Jump
      UF             - Jump forwards
      F              - Walk forwards
      DF             - Crouch
      D              - Crouch
      DB             - Crouch or low guard
      B              - Walk backwards or high guard
      UB             - Jump back
      F, F           - Forward dash
      B, B           - Back dash
      xy             - Recovery (when falling)

    Throws
    ------
      F/B + z (when close) - Trident Throw

    Special Attacks
    ---------------
      D, DF, F + x   - Fireball
      D, DF, F + y   - fireball
      D, DF, F + z   - Fireball
      D, DF, F + b   - Tsunami
      D, DF, F + c   - Trident roll 
      D, DB, B + a   - Tornado

      a+x            - call striker
      b+y            - trasspassing
      c+z            - fussion with earth
    
    Fields
    ------
    F + x+y         - armor field 
    F + a+b         - drain field
    F + b+c         - invencibility field
    F + x+c         - paralize field
    Hyper Attacks 
    -------------
     a+b+c = taladro por el suelo
     x+y+z = taladro
