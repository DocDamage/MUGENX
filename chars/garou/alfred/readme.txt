1.0 Introduction
---------------------------------------------------------------
 One of my favorite character! Alfred was ripped from both
 RBFF2 and RBFFS: Dominated Mind (PSX). Some people may not
 like this char...but who cares! I DO! Like all my characters,
 Alfred is close to original. So anything you see wrong, please
 don't complain, report!

4.0 Move List
---------------------------------------------------------------

-=[4.1 Basics]=-

- Light Attack
	A
- Medium Attack
	B
- Hard Attack
	C
- Knockdown Kick
	B + B
- Low Side Kick
	F + B
- Taunt
	Start Button

-=[4.2 Special Attacks]=-

- Agmenter Wing
	D, DF, F + A
- Divergence
	D, DF, F + C
- Mayday! Mayday!
	in air, D, DB, B + B, tap B
- Critical Wing
	D, DB, B + A/C
- S. TOL (Throw)
	F, DF, D, DB, B + B

-=[4.3 S/P Power Attacks]=-
- S. Power
	in air, F, HCF + BC
	in air, D, DB, B + BC
- P. Power
	F, B, DB, D, DF, F + C
	D, DB, B, D, DB, B + C
- Final Impact
	After weak critical wing (D, DB, B + A),  D, DB, B + C
