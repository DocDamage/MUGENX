WHATS DONE
=================================================================================================
11/18/00
--------
-> Rebuilt Hotaru to make her move accurate. The following moves were modified(M) or redone(R):
	(R) Sou Shou Shin
	(M) Ten Shin Shou
	(M) TOP Attack
	(M) Ren Geki Shuu
	(R) S Power & P Power - Sou Shou Ten Ren Ge
	(R) S Power & P Power - Ten Shou Ran Ki
	(R) Hakki Shou
        (M) Kobi Kyaku
	(R) Shajou Tai
        (M) S Power & P Power - Shinkuu Hakki Shou
-> Tweaked walking velocities & running velocities
-> Removed the Tiger super
-> Fixed a projectile sprpriority bug during the Hakki Shou
-> Fixed it so you can only do 1 Hakki Shou at a time
-> Modified all super shadows
-> Modified several hitdefs
-> Removed the Kobi Lightning Dragon Super & Replaced it with Shin Kobi Kyaku
-> Added the words "TOP IN" when Hotaru enters TOP mode
-> Added the words "Just Defended" when Hotaru uses just defense
-> Enabled Guard Cancels during Just Defense
-> Added more sounds
-> Added more explods
-> Changed knocked into air animation
-> Fiddled with her button layout a bit


9/8/00
-------
-> Now Compatible with Mugen 6.27
-> All new required sprites added
-> New basic animations (knocked into air etc)
-> More frames (now over 1300, formerly over 1100)
-> Redid the super fireball (its different)
-> Modified the P Power version of the Dragon super (it now looks different than the S version)
-> More sounds
-> Improved her throw
-> Added more special effects (like dust during Sou Shou Shin)
-> Paid more attention to other details
-> Commands for some moves were fixed or changed
-> Many states have been optimized, thus improving overall speed
-> Fixed the ending of the P Power Sou Shou Ten Ren Gae

Follow the procedure below to add in Hotaru!
--------------------------------------------

First extract the hotaru.zip to chars/hotaru from the mugen 
directory!Then open data/select.cfg
Under the [Characters] sections,add in the characters like this!

[Characters]

hotaru, stages/XXXstage.def -> for adding HOTARU!

This character is to be used at your own risk. If any damage is caused to
