                           **NOTE**

If you dislike the button layout, open up Gato.def in a text
editor.  Note the second "cmd =" line, commented out.  Uncomment
this one and comment out or delete the original.  The alternate
should be more suited to a Capcom-style button layout.  The
default CMD file is designed to mimic the Neo*Geo's button layout.

--------------------------------------------------------------------

To use the "Just Defended" system:
  Block at the last possible instant, and Gato will flash blue for
  a moment, and gain back a tiny bit of life.

To use the T.O.P. (Tactical Offensive Position) Mode system:
  Depending on the button you use to select, Gato's T.O.P. zone
  will be in either the upper, middle or lower third of the
  lifebar.  When in this mode, he will begin flashing white, and
  slowly gain life, up until the highest point of the T.O.P.
  zone.

                           Move List

Legend:
WP  = Weak Punch            SP  = Strong Punch
WK  = Weak Kick             SK  = Strong Kick
qcf = down, down-forward, forward
qcb = down, down-back, back
dp  = forward, down, down-forward

****** THROWS ******
Daien Shin                 when close, forward + SP
Danzetsu Tai               when close, forward + SK

****** Command Normals ******
MuRanGeri                  forward + WK
Kuuchuu FuriMuki           in air, SP + SK (same time)
SaiGaku                    forward + WP
unknown (shoulder charge)  d + (WP + WK) (same time)

****** Special Moves ******
ShinGa (weak)              qcf + WP
   Tsuika Kougeki            forward, forward + WP
ShinGa (strong)            qcf + SP
   Tsuika Kougeki            forward, forward + SP
RaiGa (weak)   [break]     dp + WK
RaiGa (strong) [break]     dp + SK
FuuGa (weak)               qcb + WK
FuuGa (strong)             qcb + SK
   KouGa                     WP
   SenGa                     WK
   KyuuGa                    SP
   KatsuGa                   SK
Houzan Sai HekiGa          charge down, up + SP

****** S.Power Moves (requires one level of super meter) ******
Zero Kiba                  qcfx2 + WP
Tatsu Kiba                 qcfx2 + WK

****** P.Power Moves (requires two levels of super meter) ******
Zero Kiba                  qcfx2 + SP
Tatsu Kiba                 qcfx2 + SK
Tenryuu Retsukiba          dp + (WP + WK) (3 times)

****** T.O.P Attack ******
Mouko Kouhazan             when in T.O.P. mode, SP + SK
