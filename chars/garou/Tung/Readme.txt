Tung Fu Rue v1.0 by Silencer (aka Silencer66 in the Developpemnt & Charasson Forum).
Well my first char (come from Fatal Fury), I tried to make him as accurate as possible 
and add him some originals moves. I hope you'll enjoy as much as i liked convert him to 
Mugen.
This char is for now only downloadable at Mugenpowa (Http://www.Mugenpowa.fr.st). 
Please ask me first before host him in your site.

The moves are listed below :

Legendary : B = Back, DB = Down-Back, D = Down, DF = Down-Forward, F = Forward
            P = Punch, LP = Low Punch, HP = High Punch
            K = Kick, LK = Low Kick, HP = High Kick
            RBS = Real Bout Special, RB2 = Real Bout 2, FFS = Fatal Fury Special

Tung is a 4-button character (I don't like the 3-buttons output of the Real Bout series)

* Special Moves :

- Light Ressen Shou (Original Move) :
  Tap LP quickly

- Strong Ressen Shou (Original Move) :
  Tap HP quickly

- Shou-Ha (RB2 Move) :
  D, DF, F, LP

- Dai Shou-Ha (RBS Move) :
  D, DF, F, HP

- Gekihou (FFS Move) :
  D, DF, F, LK

- Geki-Ha (RB2 Move) :
  D, DF, F, HK    hold HK then release to make this move interesting

- Shippu (RBS/RB2 Move) :
  D, DB, B, P

- Senpu (Original Move) :
  B, DB, B, K

- Spit Fireball (RBS Move) :
  F, DF, F, P

- Ressen Kyaku (RBS/RB2 Move) :
  F, DF, F, K

- Taunt :
  Start

  Meditation (RB2 move, in this state some specials attacks can be performed) :
  "Taunt", Start

  Super Taunt (Tung can gain a lot of power in this state depending of the speed at which he rubs his back) : 
  "Meditation", x   then tap x quickly to make moving faster his towel/belt

  Shin Shippu (Stronger & faster) :
  "Meditation", y

  Shin Senpu : (Turns faster) :
  "Meditation", a

  Shin Ressen Kyaku (Stronger & Faster, invincible when doing that) :
  "Meditation", b

  Fall (not a move, Tung just miss the Meditation if Start is pressed again) :
  "Meditation", Start

* Super Moves :

- Senpu Gouken (RBS/RB2 DM, 1 bar) :
  F, B, D, F, LK

- Outrageous Man (RBS SDM, 2 bars) :
  F, B, D, F, LP

- Shin Geki-Ha (RB2 SDM, 2 bars) :
  F, B, D, F, HK

- Ancients Gi-Fury (Original Super, 3 bars)
  F, B, D, F, HP    then make D, DF, F, HP to throw the fireball

* Helpers (sure this is not difficult to find how to call them) :

- Terry Bogard :
  "z"

- Andy Bogard :
  "c"
