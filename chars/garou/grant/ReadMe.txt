 Installation
+++++++++++++++
 DownLoad 1 file named "Grant_0101.zip" or "Grant_0731.zip".
 The "Grant_????.zip" contains 15 files shown below.
  Grant.air		Grant7.act
  Grant.cmd		Grant8.act
  Grant.cns		Grant9.act
  Grant.def		Grant10.act
  Grant.sff		Grant11.act
  Grant1.act		Grant12.act
  Grant2.act		Grant.snd
  Grant3.act		ReadMe_J.txt (In Japanese)
  Grant4.act		ReadMe.txt (In English, this file)
  Grant5.act		Skill.zip (Containes commands)
  Grant6.act

 * If you use Mugen0627, then delete "Grant.cns" and rename "Grant2.cns"
   to "Grant.cns".

 Unzip a file then, put these files into 1 folder named "Grant".
 Then Put "Grant" folder into your Mugen "charas" folder.

 Ex.)
   muk00101-----charas
              :    |____Grant
              :    :       |____Grant.air
              :    :       :
              :    :       :
              :    :       :

 Add this line in your "select.cfg" (or "select.def")in "data" folder.

 Grant, stages/******.def

 Replace ****** with your favorite background name.

 Ok, run your Mugen then the Grant's face is added your character
 select screen. Let's enjoy !!!
