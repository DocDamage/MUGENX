Notes
-----------------------------------------------
If u want to use the Alternate cmd file which will give the buttons a 
Capcom style layout you'll have to modify the Jae.def file like this:

--Before--		
cmd     = Jae.cmd     
;cmd     = JaeAlt.cmd     

--After-
;cmd     = Jae.cmd     
cmd     = JaeAlt.cmd     

Make sure u do this correctly otherwise u could mess things up, if u have 
any trouble just E-Mail me.

------------------------------------------------
TOP Mode
------------------------------------------------

To use the TOP Mode (Tactical Offensive Position) system:
Depending on the button you use to select, Jae Hoon's T.O.P. bar
will be in either the upper, middle or lower part of the
lifebar.  When in this mode, he will begin flashing white, and
slowly gain life, up until the highest point of the TOP zone.

---- 
Key
----

Button      TOP section     Palette
-------------------------------------
  A           upper            1
  B           middle           1
  C           lower            1
  X           upper            2
  Y           middle           2
  Z           lower            2
Start+A       upper            3
Start+B       middle           3
Start+C       lower            3
Start+X       upper            4
Start+Y       middle           4
Start+Z       lower            4

------------------------------------------------
Just Defend
------------------------------------------------

To use the Just Defended system:
Block at the last moment, and Jae will flash blue and gain 
back a tiny bit of life.

------------------------------------------------
Moves List
------------------------------------------------
I have made Jae's button layout to be exactly the same as in Garou, 
this is partly so that he is as accurate to the original as possible,
also because I like the button layout in Garou

A = Weak Punch
B = Weak Kick
X = Strong Punch
Y = Strong Kick
Start = Taunt

==*special moves*==-----------------------------------------------------------------------

Nericage - A+B

RoundHouse Kick - down+A+B

Shou Kyaku Hou - Press B when landing from Hop Back(back*2) very good surprise attack

Hangetsu Zan - QCB+B or Y

Ryuusei Raku - QCF+B or Y

Shakka Shuu - QCF+A or X (hold to delay the attack, Jae is invulnerable 
                          to normal attacks during this time)

Hienzan - Charge down(1sec) up+B or Y (on Hienzan with "Y" press Down+Y at 
                                       the highest point in the air, or 
                                       after the third hit, to add an extra hit)

Hishou Kyaku - down+B or Y in air (press d/f+B or Y when landing from Hishou
                                   Kyaku to add an extra sliding attack)

Hassei Waza - QCB+B or Y after Hishou Kyaku makes contact

Ku Sa Jin - F,D,DF+A or X 

=====TOP attack=====----------------------------------------------------------------------

X+Y (Can only be performed while in TOP mode)



==*super moves*==-------------------------------------------------------------------------
