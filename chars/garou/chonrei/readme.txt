			JIN CHONREI (by Luchini) = ripped from Real Bout Series (Neo Geo)

HOW INSTALL

-Unzip this file in the chars directory of Mugen;
-Open the file select.def (this file is in the data directory of Mugen) with
 a text editor;
-Search the line where you can see [characters];
-Under this line write the name of the directory of the char;
-Save the file and load Mugen;
-That's all.
 
BUTTONS

A = weak kick
B = strong kick
X = weak punch
Y = strong punch
C or Z = dogde
start = taunt

MOVES

Two punches or Two kicks + B or F (recover, when in air, or roll, when in ground)
F + y near opponent (throw)
hold down-forward to crouch walking

-Special moves

D, DF, F + x
D, DF, F + y (keep y pressed to charge the move)
F, F + any punch
F, D, DF + any punch (can be used as a counter move, need 500 or more power)
D, DB, B + any kick (can be done in air)
D, DB, B, F + x (can be done in air)
D, DB, B, B + hold down y(release or press y again to release the move)

-Super moves:

F, B, DB, D, DF, F + any punch (level 1)
F, B, DB, D, DF, F + two punchs (level 2)
D, DB, B, F + any kick (level 1)
D, DB, B, F + two kicks (level 2)
