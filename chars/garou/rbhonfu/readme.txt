◇基本技◇
 小攻撃　= X
 中攻撃　= A
 大攻撃　= Y

◇必殺技◇
九龍の読み             =  ４１２３６＋y
黒龍                   =  空中の相手４１２３６＋y
電光石火の天           =  ２１４＋a 
電光石火の地           =  ２タメ６+a
電光パチキ 　　　　　　=　電光石火の地中にy連打 
炎の種馬　　　　　　　 =  ２１４＋x(x連打で追加攻撃)
制空烈火棍             =  ６２３+x or y

◇超必殺技◇
爆発ゴロー             =  ２１４１６＋x,a同時押し
(ゲージ１使用)
爆発ジロー             =  爆発ゴロー中にレバー四回転
　　　　　　　　　　　　　爆発ゴロー中に６４１２３(簡易コマンド)

◇潜在能力◇
カデンツァの嵐         =  ２１４１６＋y
(ゲージ2使用)

よかトンハンマー       = ライフが3分の1の時６４１２３＋y 
(ゲージ2使用)
