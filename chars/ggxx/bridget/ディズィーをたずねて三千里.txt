＊ヨーヨーで遊ぼう♪（これのどこがヨーヨーだ！ってツッコミは無しで。）
HSボタンは各種ヨーヨー遊びに対応です。
　・HSとレバーで任意の方向にヨーヨーを設置できます。（地上5方向、空中8方向）
	地上で上に設置する場合、HSを先に押してからレバーを入れるのがコツです。

　・設置した段階で、もっかいHSを押すと戻すことが出来ます（地上・空中）
	この時、攻撃力発生して相手に当たります。

　・設置したヨーヨーが戻ってくるまで再び設置はできません（一個のみ）

　・設置した段階でコマンド入力（ヨーヨー技の一部）で熊に化けて攻撃します。
  
　・ローリング移動(以下R移動)は、動作中に他の空中行動(R移動含)に移行できます。

  ・ローリング墜落はローリング移動を着地しないで数回以上行うと出せます。
    …というか、墜ちます。攻撃判定あり。墜落後気絶。レヴァガチャで復帰可能。

　・性格が変わった時は音ならすように。つまり相手にもわかってしまいます。

　・ロジャーラッシュ(殴りかかる)
	・通常性格(最大5hit・速度普通)
	　・終了条件・攻撃終了、自分かブリジットが攻撃される、ブリジットに近づく、時間。
	・EX性格(最大3hit・速度激遅)
	　・終了条件・攻撃終了、ブリジットに近づく、時間。
	
　・ジャックドロジャー(回転刃)
	・通常性格(最大3hit・速度遅)
	　・終了条件・ブリジットに近づく、時間。
	・EX性格(最大5hit・速度早)
	　・終了条件・攻撃される、ブリジットに近づく、時間。
	
　・ロジャーハグ(サーチ)
	しばらく相手を補足。この間ロジャー技を出すと敵位置から発動。
	R移動は相手に向かう。性格の違いは・・回転と透過、抱きつく時間。

　・俺とキルマシーン(燃える自転車)
	最大12hit・速度 普通/激遅
	攻撃終了か時間まで戻らない。	

これらを駆使してトリッキーな動きで遊べます。

＊こんふぃぐれーしょん：
・ボイスセレクトについて
	原作ではセリフタイプが決まってますが、ランダムになってます。
	原作どおり固定にしたい場合、
common.cnsの一番下↓の部分を変更してください(0、1、2）でそれぞれ固定、3でランダム
;--------------ブリジット　ボイスタイプ(0,1,2) default = 3(random)
[state 5900,];
type = varset
trigger1 = time = 0
var(1) = 3

☆戦闘中、ジャンプ中にスタートを押すごとにR->0->1->2->Rとかわります
　
・同様に、ロジャーが喋るかどうか、↓部分を変更。
;----------------ロジャー　ボイス ON = 1 OFF = 0
[state 5900,];
type = varset
trigger1 = time = 0
var(59) = 1

・SPモードではないけどデバックに使ってたモードを解放します
一色カラーはアレだしなんなのでありません、変わりに好きなパレットを指定できます
（常時ゲージＭＡＸ：バーストゲージがたまりやすい：体力にかかわらず一撃必殺技が発動可能）

デフォルトは7,8,9(スタートを押しながらa,b,c)
例１：5(y)カラーを設定するなら  var(41) = 7 (var(42) = 7 　と同じ数字にします
例２：全色(!)にしたい場合は  var(41) = 1 var(42) = 12   です
;--------------------------SPモード範囲設定A　1-12 var(42)より同じか「小さい」数字
[state 5900,spmodeA];
type = varset
trigger1 = time = 0
var(41) =7

;-------------------------SPモード範囲設定B　1-12 var(41)より同じか「大きい」数字
[state 5900,spmodeB];
type = varset
trigger1 = time = 0
var(42) = 9

☆簡単に設定できるよう、範囲指定か単体指定です、飛び地指定はできません（2と6とかね）
var(41) にはvar(42)より同じか小さい数字を、
var(42) にはvar(41)より同じか大きい数字を設定しないと、無効になります。
var(41) <= var(42)　です。
