*Origem:

Este char foi ripado do jogo "Street Fighter 3: 3rd Strike" pelo Joram. Todos os efeitos foram ripados dos seguintes jogos: "Marvel vs Capcom", "Marvel vs Street Fighter", "Street Fighter Alpha 3" e "Super GEM Fighters" por mim. Os sons foram tirados do "Sean" do Ethan Lives, do site BMT(Brazil Mugen Team), do "Blaze Agent" do Ethan Lives e do Sound Pack também ripado pelo Joram.

*Sobre a criação:

Primeiramente, este Sean não é uma conversão perfeita do jogo "Street Fighter 3". Ele foi feito no estilo "Marvel vs Capcom" onde foi aproveitado o melhor dos dois jogos para fazer o seu gráfico compatível com o seu estilo. 
Algumas animações foram editadas por mim como:
- 1 sprite na Air Throw
- Movimento do Air Burst  

*Paletas:

- Ele tem 12 paletas 
.botão A: SF3 
.botão B: SF3(2)  
.botão C: SF3(3) 
.botão X: MvsC 
.botão Y: MvsC(2) 
.botão Z: SF3(4) 
.botões Start + A: SF3(5) 
.botões Start + B: SF3(6) 
.botões Start + C: SF3(7)
.botões Start + X: SF3(8) 
.botões Start + Y: SF3(9)  
.botões Start + Z: SF3(10)


*GOLPES:

Básico:

- Comandos:
.U - para cima (up)   
.D - para baixo (down)
.F - para frente (forward)
.B - para trás (backward)
.X - soco fraco   
.Y - soco médio
.Z - soco forte 
.A - chute fraco 
.B - chute médio 
.C - chute forte  
.socos - qualquer soco
.chutes - qualquer chute
.(c) - segurar o botão indicado

- Super Pulo:
.D, U

- Super Pulo para Frente:
.D, U + F

- Super Pulo para Trás:
.D, U + B

- Impulso para frente: 
.F, F

- Impulso para Trás:
.B, B


Especiais:

- Throw com os braços: 
.(perto do inimigo) F ou T + Z

- Throw com as pernas: 
.(perto do inimigo) F ou T + C 

- Throw aéreo:
.(perto do inimigo) F ou T + Z (no ar)

- Sean Pachiki
.F + Z

- Rolling Sobat
.F + C 

- Burst:
.D, DF, F + X (fraco)
.D, DF, F + Y (médio)
.D, DF, F + Z (forte)
OBS: Pode fazer no ar.

- Dragon Smash:
.F, D, DF + X (fraco)
.F, D, DF + Y (médio)
.F, D, DF + Z (forte)

- Tornado Kick:
.D, DB, B + A (fraco)
.D, DB, B + B (médio)
.D, DB, B + C (forte)
OBS: Pode fazer no ar.

- Ryuubi Kyaku:
.D, DF, F + A (fraco)
.D, DF, F + B (médio)
.D, DF, F + C (forte)

- Sean Tackle: 
.B, BD, D, DF, F + X (fraco)
.B, BD, D, DF, F + Y (médio)
.B, BD, D, DF, F + Z (forte)
OBS: Segure soco para que o Sean possa agarrar o inimigo.

- Parry:  
.F - ao mesmo tempo que o inimigo atacar. (em pé)
.B - ao mesmo tempo que o inimigo atacar. (agachado)
.F - ao mesmo tempo que o inimigo atacar. (no ar)
OBS: Defesa especial que dá chance de contra-ataque, e não perde life.

- Guard Push: 
.Bloqueando, F + 2 socos ou 2 chutes
OBS: Bloqueando = "(c)B" enquanto o inimigo ataca; Defendendo.

- Recovery Roll: 
.B, DB, D + A ou X (fraco)  
.B, DB, D + B ou Y (médio)
.B, DB, D + C ou Z (forte)
OBS: Golpe para se recuperar rápido do ataque do inimigo. Fazer antes de cair no chão(HitGround).

- Alpha Counter: 
.Bloqueando, B, DB, D + A + X (Sweep)  
.Bloqueando, B, DB, D + B + Y (Ryuubi Kyaku)
.Bloqueando, B, DB, D + C + Z (Shouryuu-Ken)
OBS: Bloqueando = "(c)B" enquanto o inimigo ataca; Defendendo.


Supers:
(precisa de uma barra de poder cheia(1000 de poder), para fazê-los)

- Hadou-Burst: 
.D, DF, F + 2 socos
OBS: Pode fazer no ar.

- Shouryuu Cannon: 
.D, DB, B + 2 socos 
OBS: aperte qualquer soco rapidamente para adicionar Hits.

- Hyper Tornado:
.D, DB, B + 2 chutes


*Add-Ons:

- Combo Counter
OBS: Diminui um pouco os danos do Ryu num combo, para ficar menos apelativo.

- Sua provocação(taunt) é um ataque.
