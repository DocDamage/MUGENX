 Installation
+++++++++++++++
 DownLoad 1 file named "Balrog.zip".
 The "Balrog.zip"  contains 24 files or folder shown below.
  Balrog.air		Balrog07.act
  Balrog.cmd		Balrog08.act
  Balrog-N.cns		Balrog09.act
  Balrog-N_alt.cns	Balrog10.act
  Balrog-S.cns		Balrog11.act
  Balrog-H.cns		Balrog12.act
  Balrog.def		Balrog13.act
  Balrog.sff		Balrog.ico
  Balrog01.act		ReadMe_J.txt (In Japanese)
  Balrog02.act		ReadMe.txt (In English, this file)
  Balrog03.act
  Balrog04.act
  Balrog05.act
  Balrog06.act
  Skill (Folder)

 Unzip a file then, put these files into 1 folder named "Balrog".
 Then Put "Balrog" folder into your Mugen "charas" folder.

 Ex.)
   muk10414-----charas
              :    |____Balrog
              :    :       |____Balrog.air
              :    :       :
              :    :       :
              :    :       :

 Add this line in your "select.def" in "data" folder.

 Balrog, stages/******.def

 Replace ****** with your favorite background name.

 Ok, run your Mugen then the Balrog's face is added your character
 select screen. Let's enjoy !!!

++++++++++++++++
 Commands
++++++++++++++++
 Please show "Skill_E.htm" in the "Skill" folder.
 Button layout is below...

  X Y Z
 (l ; :) : Deffault Keys
  A B C
 (, . /) : Deffault Keys

 X...Light Punch  ,  Y...Mid  Punch  ,  Z...Hard Punch
 A...Light Kick   ,  B...Mid  Kick   ,  C...Hard Kick

++++++++++++++++++
 Featuers
++++++++++++++++++
 / Air recover or fall recover
   - Air recover -
   Press 2 or 3 Punch Buttons , when she can recover.
   - fall recover -
   Press 2 or 3 Kick Buttons , when she can recover.

 / Zero/Alpha Counter
   During she is guarding, "Forward + same strong punch
   & kick button".
   ex.)
        Forward + (Light Punch + Light Kick)

 / High Jump
   Same as KOF series.
