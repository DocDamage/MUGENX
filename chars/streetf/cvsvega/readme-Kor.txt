  조작법
  ------

    기본 조작
    ---------
      D - 아래
      F - 앞
      U - 위
      B - 뒤
      x - 버튼 X (약펀치)
      y - 버튼 Y (중펀치)
      z - 버튼 Z (강펀치)
      a - 버튼 A (약킥)
      b - 버튼 B (중킥)
      c - 버튼 C (강킥)

    기본동작
    --------
      U              - 점프
      UF             - 전방점프
      F              - 전방걷기
      DF             - 앉기
      D              - 앉기
      DB             - 앉기 또는 하단가드
      B              - 후방걷기 또는 상단가드
      UB             - 후방점프
      F, F           - 전방대시
      B, B           - 후방대시
      x+a            - 낙법 (추락시)
       
    기본 상단공격
    -------------
      x              - 약펀치
      y              - 중펀치
      z              - 강펀치
      a              - 약킥
      b              - 중킥
      c              - 강킥

    기본 하단공격
    -------------
      x              - 약펀치
      y              - 중펀치
      z              - 강펀치
      a              - 약킥
      b              - 중킥
      c              - 중킥

    기본 공중공격
    -------------
      x              - 약펀치
      y              - 중펀치
      z              - 강펀치
      a              - 약킥
      b              - 중킥
      c              - 중킥

    잡기
    ------
      F/B + y/z                  - 데들리 드로우
      F/B + b/c                  - 데드 라이즈

    필살기
    ------
      B 모으고 F + Punch                  - 싸이코 크러셔

      B 모으고 F + Kick                   - 더블 니 프레스

      D, DB, B + Punch                    - 싸이코 임팩트

      F, D, DF + Punch                    - 싸이코 배니시

      D 모으고 U + Punch                  - 데블 리버스

      D 모으고 U + Kick                   - 헤드 프레스

      헤드 프레스 중 펀치                 - 써머쏠트 스컬 드라이버

    초필살기
    --------

      D, DF, F, D, DF, F + Punch          - 허트 브레이크 디스페어

      D, DF, F, D, DF, F + Kick           - 니 프레스 나이트메어
