1. Overview
-----------------------------------------------------------------------------

This is my conversion of Cody, to the M.U.G.E.N. engine. I started him many
many moons ago, but he was left un-updated for about six months. However, I
have been sitting on an updated one for some time. Hence this release. Now 
that i have "returned" from my long hiatus, I decided to release it, so I 
could update my site.

Keep in mind, that I am simply releasing what i have had for some time now. 
My current and undivided attention is on Jon Talbain right now, who i am 
redoing from scratch, instead of simply updating. Therefore Cody gets thrown
on the back burner for now.

Many things still need to be fixed and finished. Please remember that.

And BTW, this is the OFFICAL update to Cody. I realize that others have 
"unoffically" updated him (With varying results, I've heard), so this is the
true one.

AND one final thing. I know there are many complaints about the Criminal 
Barrier super. I haven't decided what I'm going to do with it yet. In the 
meantime, go into the CMD and disable it if it bothers you that much.

What's New
----------

-Syntax updated to work with 11.29.00 MUGEN
-The 10 new required sprites introduced in 6.27.00 MUGEN has been implemented (Not 
really done well yet - will improve later)
-Sounds re-recorded for much better quality (I will downsample them in the 
future to reduce size; cody.snd is HUGE :< )
-Damage reduced and balanced (Yes, Deux, reduced MAJORLY >:P)
-Code for Criminal Upper adjusted - more accurate to SFA3 and doesn't juggle
anymore
-Added Custom Combo system, which was implemented by Shadow Watcher. (Uh, this is a 
bit unbalanced at the moment, so disable if you don't like it)
-Some tweaks here and there
-Shadow Watcher's Bad Hurricane has been disabled for now, until it gets 
tweaked. I tried to modify the damage but failed. I'll have Shadow look it over.

Its not much, but hey, he works in the new MUGEN (relatively) bug-free >:P

2. Installation and Use
-----------------------------------------------------------------------------
You must have the 11.29.00 version of M.U.G.E.N. to use this character. You 
can get it at http://www.elecbyte.com .

Simply add this line in select.def:

cody

Or if you want to use a Background with Cody:

cody, stages/stage.def

The following files should be in this zip:

cody.def
cody.cmd
cody.cns
cody1.cns
cody2.cns
cody-guy.cns
cody-EX.cns
cody.sff
cody.snd
cody1.act
cody2.act
cody3.act
cody4.act
cody5.act
cody6.act
readme.txt <---- This TXT

3. Moves List

Basic
----------
Light Punch = X
Medium Punch = Y
Hard Punch = Z
Light Kick = A
Medium Kick = B
Hard Kick = C

Alternate Medium Punch = F + Y
Hop Kick = F + C

Special
----------
Bad Stone (Still unfinished) = QCF + P

Ruffian Kick = QCF + K

Criminal Upper = QCB + P

Guy Summon = HCB + K

Custom Combo: Uses Super Meter = 2K1P or 2P1K

Super
----------
Final destruction = QCFx2 + P (LP = Level 1, MP = Level 2, HP = Level 3)

Dead End Irony = QCFx2 + K (LK = Level 1, MK = Level 2, HK = Level 3)

Criminal Barrier = QCBx2 + P (LP = Level 1, MP = Level 2, HP = Level 3)

Bad Hurricane (Currently Disabled) QCBx2 + P QCBx2 + P (LP = Level 1, 
MP = Level 2, HP = Level 3)
