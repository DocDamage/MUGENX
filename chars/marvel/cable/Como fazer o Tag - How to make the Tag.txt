MODIFICAÇÕES NO ARQUIVO CMD:

	Acrescente no "Super Motions":

[Command]

command = ~D, DF, F, c+z

[Command]
name = "DoubleDragonCounter"
command = ~B, DB, D, c+z

[Command]
name = "SnapBack"
command = ~D, DF, F, y+b

	Acrescente logo após o "2/3 Button Combination":

;-| PartnerChange |-----------------------------------------------
[Command]
name = "troca"
command = z+c
time = 1

[Command] 
name = "Assist"
command = y+b
time = 1

	Acrescente logo após o "[Statedef -1]":

;---------------------------------------------------------------------------
;Double Hyper Combo
[State -1]

triggerall = command = "DoubleDragon" && var(34) = 1 && var(38) != 3

trigger1 = ctrl

trigger3 = stateno = [4500,4999]

trigger1 = statetype = S
trigger1 = ctrl

;partner Assist

value = 4480
triggerall = command = "Assist" && var(34) = 1 && var(38) !=3
triggerall = Roundstate = 2 && statetype !=A
trigger1 = statetype = S
trigger1 = ctrl

;Double Dragon Counter
[State -1]
type = ChangeState
value = 4420
triggerall = command = "DoubleDragonCounter" && var(34) = 1 && var(38) !=3
triggerall = Roundstate = 2 && statetype !=A && power >= 1000
trigger1 = ctrl && StateNo = [150,153]

	Acrescente logo após o "st=" um st extra (st1, st2...):
	Exemplo:

st2 = TagBattle.cns   ;Tag mode

	SE seu personagem usa o [Statedef -2] e / ou o [Statedef -3], copie os comandos das seções "[Statedef -2]" e "[Statedef -3]" para o arquivo CNS de seu personagem e acrescente-as junto com as outras do mesmo tipo. Isso é necessário porque o MUGEN não consegue ler essas instruções duas vezes.
