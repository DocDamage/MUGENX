Basics:
------------
Throw1:                 ~Hold Forward/Back + Hard Punch
Throw2:                 ~Hold Forward/Back + Hard kick
Recovery Roll:          ~Hold back or Hold forward when getting up

Super Jump:             ~D,U or push 2 or more kicks at the same time


Specials Arts:
------------
Hyaku Sakuchi:          ~F,DF,F + Punch or Press any punch button repeatedly (Opt FF)

Shuriken:               ~D,DF,F + any punch (Steer w/ Up or Down)

Teleport:               ~D,DF,F + any kick


Hyper Arts:
------------
Chou Shuriken (Ground/Air):    ~D,DB,B + any two punch buttons (Steer w/ Up or Down)

Hyper Hyaku Sakuchi:           ~D,DF,F + any two kick buttons

Raimenken :            	       ~qcf x 2 + Light Punch  

Glacial Spike:                 ~qcf x 2 + Medium Punch

Inferno Spiral:                ~qcf X 2 + Hard Punch
