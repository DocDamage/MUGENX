============= What is NEW 1.2 ================================
______________________________________________________________

- Bug fixes to the flying
- Ether strike teaked
- Fierce version of the divine assault, and some tweaking on the weak and medium versions
- some faster timings
- chain combos fixed
- laucher fixed
- some axis fixing
- english documents (this file, sir)
- flying command is back to normal VS style (D, DB, B, a+b or b+c)
- some damage tweaked
- Invisible jet super now it's a level 3 hyper
- Spirit of Truth fixed
- new hit sounds (versus series), the old sound file is still compatible
- redone some paletes (old ones are still compatible if you will...)
- Began coding the modes:
        She Hulk: can't use flying at all
                  midle level super armor
                  shakes ground at landing
                  is 10% stronger than normal mode
                  invisible jet won't appear at all (this includes level 3 hyper)

        DC 1 million: midle level super armor
                      shakes ground at landing
                      is 10% stronger than normal mode

        Amazon: is 15% weaker than normal mode
                gets 15% more damage than normal mode
                invisible jet won't appear at all (this includes level 3 hyper)
