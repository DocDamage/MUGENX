Kanji Kokuin v1.0 by Silencer.
ok, my 7th char (althrough this is the 2nd I release since I haven't finished the others), 
I wanted to make him completely accurate from PIM, however there are some exceptions :  
- Clsn and some axis (there is no debug bios available in PIM).
- PIM power system (I keep the "mugenized" one in order to do not disavantage Kanji).

If you see anything else that is not accurate to the game or find any bug, please let me 
know about it.

Movelist : 

Legendary : B = Back, DB = Down-Back, D = Down, DF = Down-Forward, F = Forward, U = Up
            P = Punch, LP = Low Punch, HP = High Punch
            K = Kick, LK = Low Kick, HP = High Kick
            
* Specials : 

- Cane Climb
  F+LP 
  press F, B or U for moving, D for coming back.
  press P or K for a falling attack(K version is overhead)

- Multi-cane : 
  Tap P quickly

- Old geezer projectile : 
  F, D, B, P

- Loancloth :
  B, D, F, K

- Headbutt :
  F, B, D, F, P

- Provocation(counter move) : 
  B, DB, B + K

* Supers :

- Combo Rush(cost 1 bar) :
  Charge B, F, LK+HK

- Crumbling Bushido(cost 2 bars) :
  LK+HK, LK, LK, HK
  
- Rage(free cost) :
  done automatically, when 3 provocations have been countered.
