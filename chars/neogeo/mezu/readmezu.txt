Comandos
===================================================================
              soco chute talons
    ____________|___|____|__
   /            |   |   |   \
  /    ^       [a] [b] [c]   \ <----- Golpes fortes (abc)
 |  <- | ->      |  |   |     |
 |     V        [x] [y] [z]   |<----- Golpes fracos (xyz)
 |     _________________      |
 |____/                 \_____|

Esta e a configuração perfeita para realização dos golpes, ou seja, abc em cima e xyz 
abaixo, por isso os golpes da parte de cima sao os fortes e os de baixo sao os fracos. 
O botao de cima corresponde o fraco de baixo. A seguencia é : Soco -Chute -Arma(talons)
========================================================================
Move list - Lista de golpes
========================================================================
A - Soco forte		X - Soco fraco
B - chute forte		Y - chute fraco
C - Talons forte	Z - talons fraco

-> = frente   <- = tras   | = baixo

-> + C (bem proximo) = throw (pilão)

| / <- B ou Y = YouenKyaku (chutesmultiplos)
| / <- A ou X = Gohten(giratória)
| / <- C ou Z = Joga talons abaixado (magia baixa)

| \ -> B ou Y = Mudoh SuiryuuHa (furacão)
| \ -> A ou X = RyuuhyouDan (freeze balls)
| \ -> C ou Z = Joga os Talons (magia simples)
| \ -> C ou Z = joga talons no ar (durante um pulo)    
 
| \ -> A+B+C = *Estalactites  Level 1
| \ -> X+Y+Z = *JagaRangekiKyaku (super chutes multiplos) Level 2
=======================================================================
Manhas
=======================================================================
O furacão pode ser movimentado para frente ou para tras, durante a realização do 
mesmo.
A magia (talons projetados) pode ser feita em pé, abaixado e no ar tmbm.
Bugs : eu não achei nenhum, exceto pela paleta de cor do p2 (giratória)
