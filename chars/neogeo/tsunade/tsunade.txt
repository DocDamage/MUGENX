What's this ?
-------------

This is Tsunade, a character from the game Kabuki Klash, adapted by myself for the M.U.G.E.N. fighting engine.

Kabuki Klash was created by Hudson Soft for the Neo-Geo console. 
The M.U.G.E.N. fighting engine was created by Elecbyte. It is totally free and can be found on the Net.

To play with Tsunade, download the engine and read its instructions.


Commands
--------

Standard Moves :
   Run      : [fwd],  [fwd]
   Hop back : [back], [back]

   Roll     : [down] while running
   Big jump : [up]   while running


Normal Attacks :
   Slashes : [x] [y] [z]
   Kicks   : [a] [b] [c]

   Runing slash : [x] or [y] or [z] while running
   Runing kick  : [a] or [b] or [c] while running

   Throw : [fwd] + [z] or [back] + [z]


Powered Attacks :
   Super strike    : [y] + [a] (standing)
   Usonaki         : [y] + [a] (crouching)
   Throw Kunai     : [y] + [a] (air)
   Overhead attack : [y] + [a] (running)


Special Attacks :
   Kaiten Koma           : [down], [down] + [fwd],  [fwd]  + [x] or [y] or [z]
   Namekuji Kamikakushi  : [down], [down] + [back], [back] + [x] or [y] or [z]
   Bakujin Namekuji Keri : [down], [down] + [back], [back] + [c]
   Kaitenkeri            : [fwd] + [c]
      Keriage            : [down], [down] + [fwd],  [fwd]  + [c] (when Kaitenkeri hits)


Jutsus :
   RikiOh : [down], [down] + [x] (increases attack power)
   KinGoh : [down], [down] + [y] (increases defense power)
