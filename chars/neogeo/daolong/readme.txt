--== Introduction ==--

    This is my first (but complete nontheless) version of Dao-Long, on of the
main characters in Visco's outstanding game Breaker's. He's a powerful
(not to mention stylish) character, with not many but very useful specials,
capable of beating anyone if used well. He's a charge character, so you'll
need to think ahead a bit to pull off the most damaging combos. Speaking about
the conversion, my goal was total accuracy and to make him look and feel
exactly as he does in the original game, from its original smooth controls to
its absolute lack of cheapness. I think it turned out well, but you shouldn't
trust me, so get him and tell me your impressions ;).
    And, for the first time for me, I composed an intro and an ending too. :D

    You can get his background stage at my site too.


--== How to install it ==--

    1. Unzip the file DaoLong.zip to the mugen/chars/DaoLong folder.
    2. Edit the file mugen/data/select.cfg and, below the label
       "[Characters]" (you surely will have a large bunch of character
       names here) add:

        DaoLong                (if you didn't download Dao-Long's stage)
         or
        DaoLong, stages\DaoBG.def   (if you downloaded Dao-Long's stage)



                   -----================================-----   
                      --==   M O V E S    C H A R T   ==--
                   -----================================-----   

The button layout is as follows:

X - Weak punch
Y - Weak kick
A - Strong punch
B - Strong kick

This is the original button configuration, KOF style as you can see. If you
prefer a Capcom style button configuration, please refer to the "daolong.def"
file for info on how to change this setting.

As always, we assume Dao-Long is facing right.
