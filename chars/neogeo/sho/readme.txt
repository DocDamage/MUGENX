--== Introduction ==--

    This is my first (but complete nontheless) version of Sho, the main
character in Visco's outstanding game Breaker's. Despite his looks, he has
little resemblances with Ryu or any other shotokans when you get to play as
him. He's a fun as hell character with a high combo potential, though
chaining with him requires a bit more "rythm" than usual. Speaking of the
conversion, my goal was total accuracy and to make him play exactly as he
does in the original game. I think it turned out well, but you shouldn't
trust me, so get him and tell me your impressions ;).

    You can get his background stage at my site too.


--== How to install it ==--

    1. Unzip the file Sho.zip to the mugen/chars/Sho folder.
    2. Edit the file mugen/data/select.cfg and, below the label
       "[Characters]" (you surely will have a large bunch of character
       names here) add:

        Sho                (if you didn't download Sho's stage)
         or
        Sho, stages\ShoBG.def   (if you downloaded Sho's stage)



                   -----================================-----   
                      --==   M O V E S    C H A R T   ==--
                   -----================================-----   

The button layout is as follows:

X - Weak punch
Y - Weak kick
A - Strong punch
B - Strong kick

This is the original button configuration, KOF style as you can see. If you
prefer a Capcom style button configuration, please refer to the "sho.def"
file for info on how to change this setting.

As always, we assume Sho is facing right.
