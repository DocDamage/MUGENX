    This is Slash, the cool swordsman of the game Waku Waku 7 for the NeoGeo
game system. You can get his background stage at my site too.

--== How to install it ==--

    1. Unzip the file Slash.zip to the mugen/chars/slash folder.
    2. Edit the file mugen/data/select.cfg and, below the label
       "[Characters]" (you surely will have a large bunch of character
       names here) add:

        Slash                (if you didn't download Slash's stage)
          or
        Slash, stages\SlashBG.def (if you downloaded Slash's stage)

The button layout is as follows:

X - Weak punch
Y - Strong punch
A - Weak kick
B - Strong kick
Z - Shortcut for XYAB

As always, we assume Slash is facing right.

NOTES:
------

    - Surprise attack must be blocked high.
    - Gedan Tsuki must be blocked low.
    - Slash Strike must be blocked high.
    - Darkness Wind is unblockable.
