  조작법
  ------

    기본 조작
    ---------
      D - 아래
      F - 앞
      U - 위
      B - 뒤
      x - 버튼 X (약펀치)
      y - 버튼 Y (강펀치)
      z - 버튼 Z (회피)
      a - 버튼 A (약킥)
      b - 버튼 B (강킥)
      c - 버튼 C (미사용)

    기본동작
    --------
      U              - 점프
      UF             - 전방점프
      F              - 전방걷기
      DF             - 앉기
      D              - 앉기
      DB             - 앉기 또는 하단가드
      B              - 후방걷기 또는 상단가드
      UB             - 후방점프
      F, F           - 전방대시
      B, B           - 후방대시
      x+a            - 낙법 (추락시)
       
    기본 상단공격
    -------------
      x              - 약펀치
      y              - 강펀치
      a              - 약킥
      b              - 강킥
      F + y          - 파고들어 중단

    기본 하단공격
    -------------
      x              - 약펀치
      y              - 강펀치
      a              - 약킥
      b              - 강킥

    기본 공중공격
    -------------
      x              - 약펀치
      y              - 강펀치
      a              - 약킥
      b              - 강킥

    잡기
    ------
      F/B + y/z                  - 진공던지기
      F/B + b/c                  - 내리찍기

    필살기
    ------
      D, DF, F + Punch                    - 열풍권/더블열풍권

      D, DF, F + a                        - EX열풍권(3번연속입력)

      F, D, DF + Punch                    - 비상일륜참

      F, DF, D, DB, B + b                 - 사영권

      (공중에서)D, DB, B + Punch          - 질풍권

      F, DF, D, DB, B + x                 - 막고던지기 상단

      F, DF, D, DB, B + y                 - 막고던지기 중단

      F, DF, D, DB, B + a                 - 막고던지기 하단

      D, D + b                            - 다운잡기

    초필살기
    --------
      DB, F, DF, D, DB, B, DF + Punch     - 레이징 스톰

      D, DF, F, D, DF, F + Punch          - 레이징 스톰

      D, DB, B, D, DB, B + Punch          - 진 막고 던지기
 
      F, DF, D, DB, B, F + a              - 데들리 레이브(레벨3이상)

      F, DF, D, DB, B, F + b              - 나생문(레벨3이상)
