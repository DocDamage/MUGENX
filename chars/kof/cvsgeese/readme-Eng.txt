  Controls
  --------

    Basic Controls
    --------------
      D - down
      F - forward
      U - up
      B - back
      x - button X (light punch)
      y - button Y (strong punch)
      z - button Z (rolling)
      a - button A (light kick)
      b - button B (strong kick)
      c - button C (not use)

    Standard Movement
    -----------------
      U              - Jump
      UF             - Jump forwards
      F              - Walk forwards
      DF             - Crouch
      D              - Crouch
      DB             - Crouch or low guard
      B              - Walk backwards or high guard
      UB             - Jump back
      F, F           - Forward dash
      B, B           - Back dash
      x+a            - Recovery (when falling)
       
    Basic Standing Attacks
    ----------------------
      x              - L. Punch
      y              - S. Punch
      a              - L. Kick
      b              - S. Kick
      F + y          - KnockDown Attack

    Basic Crouching Attacks
    -----------------------
      x              - L. Punch
      y              - S. Punch
      a              - L. Kick
      b              - S. Kick

    Basic Air Attacks
    -----------------
      x              - L. Punch
      y              - S. Punch
      a              - L. Kick
      b              - S. Kick

    Throws
    ------
      F/B + y               - Shinku Nage
      F/B + b               - Nage 

    Special Attacks
    ---------------

      D, DF, F + Punch                    - ReppuKen/Double ReppuKen

      D, DF, F + a                        - EX Reppuken(input 3 time)

      F, D, DF + Punch                    - HishoNichirinZan

      F, DF, D, DB, B + b                 - ZaeiKen

      (in the air)D, DB, B + Punch        - ShippuKen

      F, DF, D, DB, B + x                 - Atemi Nage Joudan

      F, DF, D, DB, B + y                 - Atemi Nage Chudan

      F, DF, D, DB, B + a                 - Atemi Nage Gedan

      D, D + b                            - Gedan Nage

    Hyper Attacks
    -------------
      
      DB, F, DF, D, DB, B, DF + Punch     - Razing Storm

      D, DF, F, D, DF, F + Punch          - Razing Storm

      D, DB, B, D, DB, B + Punch          - Shin Atemi Nage
 
      F, DF, D, DB, B, F + a              - Deadly Rave(need three power stocks)

      F, DF, D, DB, B, F + b              - Rashomon(need three power stocks)
