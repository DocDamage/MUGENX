ガイルとのイントロの追加方法です。
意味がわからない方は、CNSの以下の部分を変更してください。
[State 190, 4]
type = ChangeState
trigger1 = P2Name = "guile" || P4Name = "guile"
trigger1 = Time = 0
value = 194
を
;[State 190, 4]
;type = ChangeState
;trigger1 = P2Name = "guile" || P4Name = "guile"
;trigger1 = Time = 0
;value = 194
へ変更すると相手がガイルの場合に登場ポーズのまま固まることがなくなります。
