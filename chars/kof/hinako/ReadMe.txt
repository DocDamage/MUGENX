 Installation
+++++++++++++++
 DownLoad 1 file named "Hinako.zip".
 The "Hinako.zip"  contains 15 files or folder shown below.

 Hinako.zip----______Hinako.air
              |______Hinako.cmd
              |______Hinako-N.cns
              |______Hinako-S.cns
              |______Hinako-H.cns
              |______Hinako.def
              |______Hinako.sff
              |______Hinako01.act
              |______Hinako02.act
              |______Hinako03.act
              |______Hinako04.act
              |______Hinako05.act
              |______Hinako06.act
              |______readme_j.txt
              |______readme.txt
              |______skill (Folder)


 Unzip a file then, put these files into 1 folder named "Hinako".
 Then Put "Hinako" folder into your Mugen "charas" folder.

 Ex.)
   muk10414-----charas
              :    |____Hinako
              :    :       |____Hinako.air
              :    :       :
              :    :       :
              :    :       :

 Add this line in your "select.def" in "data" folder.

 Hinako, stages/******.def

 Replace ****** with your favorite background name.

 Ok, run your Mugen then the Hinako's face is added your character
 select screen. Let's enjoy !!!

++++++++++++++++
 Commands
++++++++++++++++
 Please show "Skill_E.htm" in the "Skill" folder.
 Button layout is below...

  X Y Z
 (l ; :) : Deffault Keys
  A B C
 (, . /) : Deffault Keys

 X...Light Punch  ,  Y...Hard  Punch  ,  Z...Z = A + X
 A...Light Kick   ,  B...Hard  Kick   ,  C...C = B + Y

++++++++++++++++++
 Featuers
++++++++++++++++++
 / Air recover or fall recover
   Press X+A or Z Button , when he can recover.

 / Quick forward or backward
   Press X+A or Z Button on the ground.

 / Guard cancel quick forward or backward (Costs 1 power gauge)
   Press X+A or Z Button , when he guarded.

 / Guard cancel Extra Attack (Costs 1 power gauge)
   Press Y+B or C Button , when he guarded.

 / Variable Jumps which is same as KOF series.
