4.0 Move List
------------------------------------------------------------------------------

Key Layout:

[ x ] [ y ] [ z ]		a - Short 		x - Jab
 | |   | |   | |		b - Forward		y - Strong
[ a ] [ b ] [ c ]		c - Roundhouse	z - Fierce


4.1 Basic Attacks
-----------------

- Toru Ken (Mantis Style)
	All Three Punch (can be done anytime)
- Ensei Ken (Crane Style)
	All Three Kicks (can be done anytime)
- Throw (punch)
	(close) f + Y/Z
- Throw (kick)
	(close) f + B/C

4.2 Toru Ken / Mantis Style Moves
---------------------------------

Special Moves:
- Kyaku Renko (Tiger Claws)
	Tap Punch Repeatedly
- Geki Ro (Rage Mantis)
	F, D, DF + Kick, Kick . . .

Super Combo:
- Zan Ei (Long Shadow)
	D, DF, F x2 + Punch
- Shin Ten Shu (God Attack)
	D, DB, B x2 + Punch
- Custom Super 1 (Based on Yang, SF3)
	D, DF, F x2 + Kick

4.3 Ensei Ken / Crane Style Moves
---------------------------------

Special Moves:
- Jya Sen
	Hold B, F + Punch
- Ouga (Phoenix Fang)
	Hold D, U + Punch
		-Hold Back, to not attack
		-Hold Forward, to forward kick
		-Hold Up, to jump to the other side of the screen
			-Hold Down afterwards to stomp

Super Combo:
- Kouga (Tiger Fang)
	in air, D, DB, B x2 + Kick
- Jya Ho Ha
	D, DF, F x2 + Punch
