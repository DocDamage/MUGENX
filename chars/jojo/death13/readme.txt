  Controls
  --------

    Basic Controls
    --------------
      DEATH13 is a 5-button character.

      D - down
      F - forward
      U - up
      B - back
      x - button X
      y - button Y
      z - button Z
      a - button A
      b - button B



    Standard Movement
    -----------------
　　※DEATH13 can't guard.
      U              - Jump
      UF             - Jump forwards
      F              - Walk forwards
      DF             - Crouch
      D              - Crouch
      B              - Walk backwards
      UB             - Jump back
      F, F           - Forward dash
      B, B           - Back dash
      xy             - Recovery (when falling)

    Basic Standing Attacks
    ----------------------
      X              - 大鎌を素早く一回転
      Y              - 大鎌を少し離して回転
      Z              - 偽スタンド攻撃
      A              - 大鎌回転しながら中距離
      B              - 大鎌回転しながら画面外まで

    Basic Crouching Attacks
    -----------------------
      X              - 大鎌横向きに回転しながら地面近くを近距離移動（数回ヒット）
      Y              - 大鎌横向きに回転しながら地面近くを中距離移動（数回ヒット後転倒させる）
      A              - 大鎌足元で横向きに回転（転倒させる）
      B              - 大鎌横向きに回転しながら地を這うように画面外まで移動（転倒させる）

    Basic Air Attacks
    -----------------
      X              - 大鎌回転させる
      Y              - 大鎌特殊移動攻撃
      A              - ※立ちAボタンに転倒効果をプラス
      B              - ※立ちBボタンに転倒効果をプラス

    Throws
    ------
      F/B + y (when close) - ※投げられません。ご、ごめんなすって

    Special Attacks
    ---------------
      D, DF, F,  x   - 小鎌発射
      D, DF, F,  y   - 小鎌発射（ランダム）
      D, DF, F,  z   - 偽オラオラッ
空中でD, DB, B,  z   - 偽エメラルドスプラッシュ！
　　　D, DF, F,  a   - 死神世界の罠

      F, D, DF,  x   - ワープ（中央）
　　　F, D, DF,  y   - ワープ（左端へ）
　　　F, D, DF,  z   - ワープ（右端へ）
　　　　　　　　　　※ワープはジャンプ中でも使用可能です

    Hyper Attacks
    -------------
  [Lv.1 skill]    D, DF, F,  a+b       - ラリホォォォ～～～！！

　[Lv.3 skill]　　B, DB, D, DF, F, x+y - ブッタ切れろーッ！！
